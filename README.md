# LS_Augment · 红魔系统增强与桌面修改

面向红魔手机的系统与应用增强项目，包含 **LS_Augment 模块**和**红魔原生桌面修改版**两个独立安装包。

LS_Augment 使用独立应用界面管理功能，通过 Root 与 Modern LSPosed 接入系统及原厂组件；桌面修改版在红魔原生桌面基础上提供最近任务堆叠样式和内存显示。仓库同时保留用于讨论和验证界面布局的网页原型。

### 当前进度

- 主要功能已整合到原生配置界面，多数设置修改后自动保存；图标和名称编辑使用“确认修改”。
- 状态栏支持单排／双排布局，并处理已识别的风扇、刷新率、液冷等独立图标容器，减少重排后的遮挡。
- 风扇跟随原厂开关，测量完成或取消后恢复原档位；不再发布模块调节风扇的常驻通知。
- 应用商店并发下载、两项独立步数功能、配置及图片迁移、实时诊断导出均已有 Android 实现。
- 最近任务堆叠及内存显示已独立到桌面修改工程，模块继续负责桌面图标和名称编辑。
- 历史分析、日志、录像和编译产物已从源码目录分离，两套项目源码均位于独立目录。

功能实现范围与逐项实机验收范围并不完全相同。本次发布校验包含两份 APK 的签名及文件对齐、模块清单和 Modern Xposed 元数据、纯 Java 功能检查与桌面静态检查；不等同于重新完成所有功能的真机测试。

## 红魔原生桌面修改版

保留原厂桌面和最近任务的数据源及主要操作，在原生最近任务视图中增加堆叠样式与内存显示，并保留标准／宫格样式。

- 横向浏览最近任务，前后卡片采用堆叠排列。
- 继续使用原生点击打开、上滑删除、清空、分屏、小窗和任务锁定流程。
- 针对进入最近任务、卡片遮挡、触摸命中和删除动画进行了调整。

当前工程基于原厂 APK 的 Smali 和资源修改，并保留自编写的 Java 辅助源码。目录和构建方法见 [桌面工程说明](redmagic-launcher/README.md)。

## 安装与使用

### LS_Augment 模块

1. 从 Releases 下载并安装模块 APK。
2. 打开模块并授予 Root 权限，在支持 API 102 的 LSPosed 中启用模块。
3. 核对模块推荐作用域；本版本新增应用中心作用域 `cn.nubia.neostore`，升级用户需检查是否已勾选。
4. 首次安装或升级代码后重启手机，再按需开启功能；后续按页面提示重启对应作用域。

应用隐藏入口可通过连续点击首页“模块状态”图标 **7 次**显示。关闭隐藏管理开关不会自动恢复已隐藏的应用，请使用“显示”操作恢复。

肩键连点需先完成本机兼容性、左右实体肩键、连点节拍及松开停止验证；模块版本或环境变化后可能需要重新测试。风扇固定转速需先测量本机档位。

### 修改版桌面

安装前保留原厂桌面 APK 和桌面布局备份，确认底包与当前 ROM 匹配。修改版使用开发签名，能否覆盖系统桌面取决于当前安装环境；需要时使用模块中默认关闭的“允许安装签名不一致的应用”选项，完成后恢复关闭。

该包用于覆盖同包名红魔桌面，不建议通过卸载系统桌面的方式安装。安装完成后重启桌面，必要时重启手机，并在原厂最近任务样式设置中选择所需样式。

## 使用边界与反馈

- 增强功能按需开启；同包名不同签名覆盖选项仅用于可信 APK，替换后的应用可访问原应用数据。
- 音量百分比是软件设置比例，不等于实测响度；风扇目标值按硬件档位匹配，不代表精确无级调速。
- 电池相关功能不重置循环、不恢复电芯容量，也不改写未知温度、电流和电压保护。
- 主题适配仅处理本地试用机制，不改变支付结果或服务器权益。
- 步数计划关闭后停止后续新增，已保存记录保留；外部设备及第三方数据源需分别验证。
- 模块未申请网络权限；健康记录通过健康应用自己的同步入口处理。

排查问题时：**开启对应详细诊断 → 重启相关作用域 → 复现 → 导出日志**。开启前的详细调用无法补录。反馈时提供机型、ROM、模块版本、复现步骤及相关日志；分享前检查导出文件中的设备和配置信息。

### 构建模块

需要 JDK 17 或更高版本、Gradle、Android SDK 36 与 Build Tools、NDK `27.2.12479018`、CMake、Ninja、Python 3 和 Bash。配置本机工具路径后执行：

```bash
./build-module.sh
```

生成 `out/LS_Augment-v2.0.0-alpha1-test20174.apk` 及 SHA-256 校验文件。版本号以 `android/version.properties` 为唯一来源，构建不会自动改号；本机构建签名由环境配置决定。

### 验证与源码打包

```bash
python tools/check-project.py
bash tools/run-java-tests.sh
python tools/test-launcher-entry-selection.py
python tools/check-launcher-recents-smali.py redmagic-launcher/src/smali_classes2/com/android/quickstep/views/RecentsView.smali
python tools/check-xiaomi-recents-stack.py
./build-source.sh
```

源码压缩包包含两套工程及桌面必要输入，排除 `.git`、编译缓存、网页依赖、历史诊断和私有签名材料。成品 APK 通过 Releases 分发。

### 网页原型

在 `ui-preview/` 执行 `npm ci`、`npm run dev`。页面用途、布局文件和运行方式见 [原型说明](ui-preview/README.md)。
