## 新增需求

1. 应用增强页增加“应用商店同时下载限制解除”开关与详情。原型不实际控制应用商店。
2. 步数计划分两步：先设开始/结束时间、随机执行次数、每次步数；再多选周一至周日。显示每日合计、随机时间示例，支持跨午夜时间范围。关闭计划后隐藏计划设置。实际执行留待手机模块阶段。
3. 模块设置新增 JSON 配置导出、导入。已验证实际下载、文件选择导入、刷新恢复及无效文件拒绝。内容包含当前原型设置，不包含账户绑定和执行日志。

## 后续落地约束

- 本轮确认的是界面原型，不是已安装模块的新功能。
- 模块阶段应使用稳定设置键和版本化 JSON 格式，并实现设置迁移；不能直接把原型的控件路径键当作长期模块协议。
- 自动保存不等于所有底层功能立即生效：保留重启作用域入口，模块阶段按各功能实际生效方式处理。
