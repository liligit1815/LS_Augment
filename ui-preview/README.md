# LS_Augment 真机界面原型

用途：对照真实模块界面讨论布局，并将用户标注落实为明确的界面修改。

## 查看

首次运行或清理依赖后先执行 `npm ci`，再运行 `npm run dev`，打开 http://localhost:3000/#home-unlocked 。右侧浏览器可以直接查看并标注。

本次原型在本地运行；之前发布的 Sites 地址尚未同步本次重建。

## 还原依据

- 当前连接的 NX809J 真机，LS_Augment 2.0-alpha1-test20169。
- Android 页面源码、1216 × 2688 真机截图与实测控件树。
- 使用手机实际字体的字符子集和真实界面图标。
- 保留原生文字换行、卡片尺寸、控件位置、分页和滚动范围；页面按手机比例整体缩放。
- 当前布局基准保存在 `app/native-pages.json`，字体和界面素材保存在 `public/`。历史截图和验收报告已清理。

## 原型范围

已覆盖主界面、各功能分类、状态栏四个配置分页、功能详情和已采集的展开状态。主要配置控件可以操作，状态栏预览跟随配置变化，滚动仅发生在配置区域。

页面使用真实 DOM 控件，不是整张截图贴图。手机系统栏与硬件读数使用演示状态。重启、应用隐藏、健康数据写入等操作不会调用手机。

2026-09-06：已按用户的 30 条标注和 3 项新增需求修改网页原型。配置自动保存在当前浏览器，刷新后仍保留；可以导出 JSON 并导入恢复。导出通过无状态下载接口兼容内置浏览器，不在服务器保存配置。原型文件标识为 `LS_Augment.UIPrototype`，不能宣称已兼容尚未修改的手机模块。

新增应用商店下载限制解除开关、两步式随机步数计划（时间范围、次数、每次步数、星期多选）、配置导入导出页。下载限制和步数执行仅展示界面和模拟状态，实际手机功能待确认布局后实施。

## 后续按标注修改

`app/native-pages.json` 保存真机布局基准。原有控件带有 `data-native-path` 和 `data-ui-label`，方便对应标注。布局调整记录到 `app/layout-overrides.ts`；重组页和新增页在 `app/revised-pages.tsx`。逐条落实情况见 `annotation-changes.md`。

`scripts/import-native.py` 可从重新采集的本地截图与控件树导入基准；需先准备脚本要求的 `../out/ui-faithful/` 输入。日常预览直接使用已保留的基准。重新导入前应检查是否会影响已确认的调整。

本轮没有修改 Android 源码或手机安装包。用户明确要求：确认网页布局后再修改模块布局。
