# LS_Augment 功能说明

适用版本：2.0.0-alpha1-test20174

LS_Augment 是面向红魔手机的系统与应用增强模块，提供应用隐藏、桌面个性化、状态栏定制、游戏辅助、风扇控制和运行诊断等功能。模块通过独立应用界面配置，需要 Root 权限及支持 Modern libxposed API 102 的 LSPosed 环境。当前主要适配和验证设备为红魔 11 Pro（NX809J）、Android 16；其他机型及系统版本需要分别验证兼容性。

## 一、应用隐藏与快捷管理

**应用隐藏**
按用户空间分别选择需要管理的应用，支持名称或包名搜索、单个隐藏与显示，以及全部隐藏、全部显示。隐藏操作保留应用数据，系统关键组件不开放隐藏。关闭隐藏管理开关不会自动恢复已经隐藏的应用，需要使用“显示”操作恢复。

**自动隐藏**
监听系统熄屏事件，自动隐藏指定范围内已配置的应用。执行不依赖模块界面保持打开，无需常驻前台通知。

**快捷磁贴**
在控制中心通过磁贴切换隐藏状态；目标状态混合或异常时，优先恢复全部显示。支持自定义磁贴图片、名称和说明，图片可选择、裁剪并恢复默认。

应用隐藏入口可通过连续点击首页“模块状态”卡片中的图标 7 次显示。

## 二、应用增强

**APP 图标名称编辑**
按空间和应用自定义桌面名称、替换图标。点击图片选择并裁剪，支持拖动和缩放，点击“确认修改”后保存。名称留空并确认即可恢复原名，也可单独恢复原图标。

**扩展应用双开**
扩展红魔原生双开候选列表，让更多普通第三方应用进入双开选择范围，并提供解除低内存限制的选项。双开空间继续由原厂框架创建和管理。

**应用商店同时下载数量**
调整红魔应用中心允许同时下载的应用数量，支持 1～50 的整数设置。修改后重启应用中心生效；实际下载速度仍取决于网络、服务器和设备状态。

**主题无限期试用**
针对已适配的原厂主题试用资源，处理本地试用到期后的恢复流程。功能范围限于本地试用机制，不改变购买状态或服务器权益。

**允许安装签名不一致的应用**
允许使用不同签名的 APK 覆盖安装同包名应用，默认关闭。共享 UID、跨应用签名权限及其他安装检查仍保留。替换后的应用可以接触原应用数据，应仅用于可信安装包。

**步数修改**
适配小米运动健康，使用前绑定本机当前账户。真实新增步数可设置 1～10 倍；随机增步可设置开始与结束时间、执行次数、每次步数和执行星期，支持跨午夜时间范围。两项功能独立控制，计划增加的步数不会再次乘倍数，并通过记录去重避免重复加入同一笔步数。已有一次性计划保持兼容；关闭功能停止后续新增，已经保存的记录保留。

## 三、系统增强

**小窗增强**
分别提供“解除小窗数量上限”和“全应用支持小窗”，扩展普通应用的小窗使用范围。可把指定应用加入“遵循原厂小窗应用”清单，使其继续采用系统原有策略。系统关键界面保留保护。

**状态栏定制**
提供布局、时钟、硬件／网速和图标四类设置，修改后自动保存并更新预览。支持调整状态栏高度、边距、两排间距，以及各组件的位置、大小和排列顺序。

时钟支持单排、双排和自定义两行格式，可显示时间、日期、星期及秒。硬件信息支持 CPU、GPU、电池温度、电流和功率；网速支持上行、下行、同排及双排显示。

通知图标和系统图标可分别设置单排或双排，电池图标单独配置。红魔风扇、刷新率、液冷及其他已识别的独立提示容器纳入空间分配，减少重排后的遮挡；空间不足时按布局区域缩放。关闭状态栏增强后恢复原厂布局。

**音量增强**
分别针对扬声器、有线／USB 耳机、蓝牙音频，设置媒体、铃声和闹钟的音量上限，范围为原厂上限的 100%～300%；支持调整每次音量按键增加的幅度。继续使用原生音量键和面板操作，实际可用增益取决于播放通道和设备，百分比不代表实测响度同比增加。

**电池与循环次数**
读取系统电量计、厂商接口和原厂历史记录，展示循环次数、当前满充容量估计、设计容量及数据来源。不同厂商字段可能采用不同统计口径。

提供“持续关闭按循环降压”，用于关闭已识别的、随电池循环次数增加而降低充电电压的原厂策略。保留循环记录及温度、电流和电压保护；该功能不修复电池老化，也不代表恢复已经损失的容量。

## 四、游戏增强

**全应用肩键与极速连点**
扩展加入游戏空间的普通应用的肩键使用资格，保留原厂肩键配置流程。极速连点支持 10～50 次／秒设置，需要先完成本机兼容性检查、左右实体肩键及连点停止验证；设备环境或模块版本变化后可能需要重新测试。实际响应还受游戏输入处理能力影响。

**AI 触发器极速响应**
调整原厂 AI 触发器的模板扫描、点击队列、策略冷却和 YOLO 扫描间隔，减少识别和执行之间的等待。识别条件与任务仍在原厂功能中配置，保留原厂识别阈值及相关复核流程。

**一键连招速度**
调整原厂录制连招的播放速度，支持 1～10 倍整数倍率，保留原始录制内容。

**超分与破坏神**
提供性能模式下的原厂超分资格放行，以及超分与破坏神共存选项，减少两种模式之间的自动互斥。仍需设备和原厂组件具备对应能力。

**风扇控制**
支持测量本机 1～5 档风扇转速，完成或取消后恢复原厂档位。根据测量结果设置目标转速，运行时匹配最接近的硬件档位，并提供已验证驱动最高档位的解限选项。

风扇控制跟随原厂开关，不会自行启动风扇；目标值不代表连续、精确的无级调速。实际转速以本机反馈为准。当前版本不再发布“LS_Augment 正在调节风扇”的常驻通知，原厂状态栏风扇图标继续保留。

## 五、模块设置与问题排查

**桌面入口管理**
隐藏或恢复 LS_Augment 自身的桌面图标。隐藏后可从 LSPosed 管理器进入模块设置。

**配置导入导出**
备份和恢复功能设置、应用选择及自定义图片。导入时校验配置与图片；账户绑定、运行日志和本机兼容性测试凭据不随备份转移。

**运行诊断与日志**
日常日志记录关键操作结果与异常，按大小滚动保存。肩键和 AI 触发器可分别开启详细诊断。

导出日志会重新采集设备与模块信息、配置、进程和 Hook 状态，并按当前诊断开关加入对应的详细调用记录。日志区分注册、回调、异常及数据缺失，帮助排查模块是否加载、是否触发和执行中出现的问题。未开启详细诊断前的调用不能补录。

排查建议顺序：开启对应详细诊断 → 重启相关作用域 → 复现问题 → 导出日志。

多数设置修改后自动保存；APP 图标名称编辑需要点击“确认修改”。首次安装或更新模块后，按页面提示重启手机或相关作用域，使新代码生效。当前版本仍处于 Alpha 测试阶段，功能实现范围与逐项实机验证范围并不完全相同。
