# 状态栏素材与字体

本功能让用户查看真实系统图标的状态，为具体组件选择图片、动画或字体。外观作用位置包括**桌面与应用、锁屏、通知中心头部、控制中心头部**，可以共享设置或分别覆盖；不包含应用通知内容、快捷磁贴或息屏显示。具体替换能力取决于原厂对象结构与当前观察结果。

运行时按真实原厂头部角色识别通知中心与控制中心；合并通知/QS 使用通知中心头部设置。未知头部角色保留原厂，不依据截图文件名或父容器外观猜测上下文。

社区仓库：[RedMagicDuo-Assets](https://github.com/liligit1815/RedMagicDuo-Assets)。首批示例可在 [v1.0.0 发布页](https://github.com/liligit1815/RedMagicDuo-Assets/releases/tag/v1.0.0)下载；用户可以只下载使用，也可以选择投稿。


## 使用入口

进入「通知与控制中心 → 状态栏自定义 → 图标素材与字体」。按显示位置配置也可进入对应方案。主布局开关关闭时，总览与素材管理入口仍然可用。

页面提供三个入口：

- **图标总览**：按名称、语义 ID、分类搜索，切换桌面与应用、锁屏、通知中心或控制中心观察位置，筛选正在显示、当前未显示、已自定义。顶部常用图样和每一行的图样都可以帮助辨认图标；点击进入详情。
- **字体**：选择统一字体，或分别覆盖时钟、网速、硬件信息、电量数字、蓝牙电量、其他状态栏文字。每个角色可以跟随统一字体，也可以明确恢复原厂字体。
- **导入与分享**：导入社区素材包、打开社区仓库、管理本地图片、导出当前方案、打开 GitHub 投稿页。

导入、选择、恢复默认首先修改本页草稿；点击「应用到状态栏」才保存。可以撤销最近的修改，也可以在返回时放弃草稿。已导入的文件会保留在本地素材库中；放弃草稿不会自动删除文件。原布局编辑器和新素材页分别管理自己的配置，避免旧布局草稿覆盖新素材设置。

运行时外观覆盖仍遵循系统界面主开关；开启「仅调整位置和大小」会暂停素材和字体覆盖。查看目录、导入和制作方案不要求先开启覆盖。

## 图标目录与真实状态

目录包含整体组件、可单独处理的内部元素，以及随当前实际上网订阅切换的「当前上网卡」角色。卡 1 / 卡 2 按物理卡槽绑定；当前上网卡按实际活动数据订阅绑定，不能与默认数据卡或第一显示行混为一谈。目录存在不代表该对象在所有 ROM 上已经验证可替换。

| 分类 | 目录内容 |
| --- | --- |
| 网络与连接 | 主、副 Wi-Fi；双卡信号；蓝牙；热点；NFC；定位；飞行模式；VPN；投屏；外接显示器；有线网络；流量节省；卫星连接；HD / IMS；双排信号整体 |
| 网络附属元素 | Wi-Fi 强度、收发箭头、标准数字；每张卡的强度、网络类型图片、收发箭头、漫游、HD / VoLTE、无网络标记 |
| 电量 | 电池整体、外壳、填充或圆环、充电与旁路充电标记；蓝牙设备电量；三合一整体 |
| 声音与设备状态 | 闹钟、勿扰、静音、音量或振动、耳机、旋转锁定、TTY、工作资料、传感器关闭、录屏 |
| 红魔专属 | 散热风扇、液冷、刷新率 |
| 隐私与系统提示 | 摄像头、麦克风、定位、屏幕共享、隐私圆点、隐私胶囊、系统活动标志 |
| 其他系统对象 | 切换用户图标、锁屏用户头像 |

列表中的图样是用于辨认和编辑的**语义示例**，不是原厂素材提取结果，也不是实时屏幕截图。详情预览同样使用明确标注的示例底图。四位置的显示状态来自 SystemUI 的实际观察，各自携带观察时间；本页前台刷新观察记录。`observedSurfaces` 仅列出最近一轮真正观察到的上下文，其余位置保留上次快照，不以最近更新时间伪装成当前状态。

需要区分以下状态：

- 「正在显示」表示完整图标当前可见；「显示为溢出圆点」表示系统将其折叠为圆点。
- 「当前未显示」可能来自模块规则、原厂条件、父容器隐藏或当前不在对应界面，详情展示可获取的原因。
- 「条件未触发」与「暂未检测到」都不能简单等同于「用户隐藏了图标」。例如没有连接相应设备时，相关视图可能尚未创建。
- 「尚未适配」或「当前只能观察」表示发现了对象，但当前没有可确认的安全替换能力。未知对象保留原厂呈现。
- 旧快照会显示观察时间与过期提示；切换到相应系统界面观察后再回来核对。主屏的新观察不会把锁屏的旧快照伪装成新数据。

隐私胶囊和圆点存在独立窗口，红魔风扇、液冷、刷新率也有厂商专有结构；它们需要单独发现和适配，不按普通系统槽位推断支持。当前工程的基线设备是 **NX809J / RedMagicOS 11.5.7MR1 / Android 16**。系统补丁、SystemUI 构建和其他机型可能改变视图结构，运行时能力、应用或回退原因以实际观察为准。

## 图片、动画与分层

普通信号样式针对强度子组件。高级素材可以指定状态及「整图」「背景层」「前景层」；同一组件的有效整图绑定优先，没有有效整图素材时按背景、原有图样、前景绘制。背景和前景仍是用户指定的装饰，制作时应避免不透明素材遮挡必要信息。

状态按语义提供，例如连接状态、信号等级、电量区间、充电、旁路充电、刷新率。静态子组件可以使用默认素材；信号、电量填充、制式、蓝牙连接状态等动态图样不能用单张默认整图代替全部状态。断网状态没有对应素材时，不退到普通强度图片覆盖原厂提示；未知状态保留原厂。

Wi-Fi 整组、移动网络整组、电池整体、双排信号、三合一、隐私胶囊含多项独立变化的信息，单个状态的整图不能表达完整组合，因此整组整图保留配置但安全回退；通过子组件样式或装饰层定制。旧包仍能导入，详情会解释未生效原因。原生图标表和绑定状态优先于电话回调后备，不从资源名称里的数字猜测信号等级，也不把缺少信号数据当作断网。

运行诊断逐项记录 `application`、`applicationReason`、`matchedState`、`matchedAsset`、`coveredBy` 和 `stateSource`，区分已绘制、等待绘制、加载失败、未映射、未知状态、不支持、原厂隐藏和位置隐藏。保存成功不等于当前条件已经触发该素材。替换图形叠乘原生透明度，原厂休眠或透明箭头不会因导入素材变成全亮。

每个绑定可设置大小 10%–400%、横纵偏移各 −64 至 64 dp、不透明度 0%–100%、水平镜像，并选择保留素材原色或跟随系统深浅色。详情同时显示浅、深背景预览。

| 类型 | 支持与限制 |
| --- | --- |
| 静态图片 | PNG、JPEG、WebP、静态 GIF；单文件不超过 8 MiB，源图片每边不超过 4096 像素 |
| 动画 | GIF、动态 WebP；单文件不超过 8 MiB，每边不超过 1024 像素，不超过 240 帧 |
| 不支持 | APNG、SVG、视频和可执行内容；APNG 导入时会明确提示改用 GIF 或动态 WebP |
| 解码 | 保留原始文件，绘制副本最长边限制为 256 像素，适配状态栏尺寸 |

预览离开前台或视图移除后停止动画。运行时对动画数量设有预算，超出预算可以保留静态帧，详情状态会说明限制；不会强制把尚未出现的系统图标显示出来。素材损坏、缺失或不支持时回退原厂呈现。

「管理本地图片素材」会标明已保存方案、当前草稿或撤销记录的引用；这些素材不能删除。真正未使用的图片可删除本地副本，删除时底层会再次核对已保存配置。字体文件目前提供选择、覆盖和恢复入口，不提供删除入口，以免误删其他页面共享使用的字体。

## 字体

支持实际内容可解码的 TTF、OTF、TTC，单文件上限 4 MiB。直接导入后显示原文件名；从素材包导入的资源使用包名与角色名辅助识别。字体选择器会标明已保存配置或草稿中的引用。

共享统一字体作为默认值；每个位置可以指定统一字体或单独角色。位置角色优先于该位置统一字体，再继承共享角色与共享统一字体；明确选择原厂字体会停止继承。页面使用所选 Typeface 实际绘制样例，未覆盖字符由 Android 的字体回退机制补充。最终字宽、基线与原厂控件仍有关，应用后应分别核对四位置。

**4G / 5G 等网络类型标志按图片素材处理**，不把它们当作可任意换字体的文本。通知内容、锁屏大时钟和息屏大时钟也不属于本页的字体覆盖范围。

## 显示与隐藏规则

原厂功能开关按实际归属放在时钟、通知、网络、电池及其他图标页面。素材详情不重复提供这些功能，导入素材或恢复主题不自动改变它们。

四位置的额外隐藏规则独立配置。它只隐藏匹配对象，不强制显示原厂当前未显示的图标；恢复继承只移除位置覆盖。原有全局隐藏、SIM 和附属元素规则继续参与结果，自绘双排信号与三合一遵循对应语义部件规则。更换素材本身不改变显隐。

## 素材包与社区分享

下载 ZIP 后选择「导入素材包」。应用先进行只读预检，展示包名、作者、许可、图片及动画数量、字体数量；确认「载入并预览」后才将验证过的资源保存到本地并合并进草稿。

合并以「作用位置＋图标 ID」为单位：包内涉及的图标替换同一位置的全部状态与图层；其他位置和其他图标保留当前草稿。字体只覆盖包内明确指定的位置与角色。旧 v1 配置按所有位置共享处理，导入旧包不会清空新建的单独位置覆盖。应用前可以撤销，点击「应用到状态栏」后一次保存配置。

「选择图标和字体导出分享包」先列出当前草稿中已绑定的图标和明确设置的字体角色，默认全选，可以按图标、按字体角色分别取消选择，也可以对某一类全选或清除选择。因此可以分享仅图标、仅字体或组合包，至少需要选择一项。每个选中图标包含其全部状态与图层；明确恢复原厂的字体角色也可导出，未明确设置的继承角色省略。

导出只包含选中配置及其引用资源，不包含设备快照、应用名单、布局、隐藏设置或其他完整配置。确认选择后立即固定导出内容；文件选择器返回时使用这份快照，屏幕旋转或后续草稿变化不会换成其他方案。需要填写包名、作者与分发许可；导入包的原始授权信息会随引用资源保留。用户应确认自己有权分发其中的图片和字体。

本地导入和导出均不会自动上传。点击「向 GitHub 投稿」会打开 [投稿表单](https://github.com/liligit1815/RedMagicDuo-Assets/issues/new?template=asset-submission.yml)，由用户选择提交。社区内容采用可下载发布包；当前通过浏览器访问仓库，不提供应用内自动安装或自动更新。

### 包格式 v1

ZIP 内包含 `manifest.json`、`images/<sha256>.<扩展名>` 和 `fonts/<sha256>.<扩展名>`。图片、字体清单使用文件内容的 SHA-256 作为键，引用必须与包内文件完全一致。推荐通过应用导出或使用社区仓库提供的示例和校验工具制作。

清单结构如下，空方案的图片和字体清单均为空：

```json
{
  "format": "RedMagicDuo.StatusBarAssets",
  "version": 1,
  "metadata": {
    "name": "素材包名称",
    "author": "作者",
    "license": "CC0-1.0"
  },
  "theme": "",
  "fonts": "",
  "images": {},
  "fontFiles": {}
}
```

`theme` 与 `fonts` 使用应用的规范化版本字符串，不接受任意设置键。图标绑定包含语义 ID、状态、图层、图片哈希、原色开关、缩放、偏移、透明度、镜像；字体映射只允许统一设置与六个文字角色。图片绑定最多 384 条、配置最多 64 KiB，同位置、同图标、同层的电量区间不得重叠。

仅共享配置仍导出原 v1 字符串；包含位置覆盖时，`theme` 使用 `2;`，每条旧十字段后追加 `all/main/lock/notification/control`；`fonts` 使用 `2;位置:角色=值`。包外层 `manifest.version` 仍为 1，包内配置分别自带版本。旧 v1 配置完整保留并可继续读写；没有精确状态的局部位置方案保留原厂，不借用另一个方案的状态。

ZIP 压缩文件上限 20 MiB，展开内容合计上限 64 MiB，文件总数最多 512。预检拒绝路径穿越、重复路径、清单之外的文件、错误哈希、引用缺失、不支持的版本、异常图片和无效字体；不会执行包内内容。

## 实现结构

| 层次 | 主要文件与职责 |
| --- | --- |
| 编辑页面 | `StatusBarAssetsActivity` 管理草稿、搜索、快照、导入、预览、撤销与保存；`StatusBarIconSamples` 绘制有明确标注的语义示例 |
| 语义配置 | `StatusBarIconCatalog` 定义目录与状态；`StatusBarThemeSpec`、`StatusBarFontSpec` 负责版本化配置与校验 |
| 资源存储 | `StatusBarAssetStore`、`StatusBarImagePolicy`、`ManagedFont` 校验、限量解码并按内容哈希存储；`StatusBarAssetReferences` 计算引用 |
| 包与备份 | `StatusBarAssetPack` 负责预检、安装、按 ID 合并、授权信息与导出；完整配置迁移由既有 `ConfigTransfer` 接入资源引用 |
| 配置与通信 | `AppConfig` 一次提交本页外观配置及明确修改的旧显示键；`LSConfigProvider` 提供受控资源访问和图标快照读取；`StatusBarInventoryBridge` 保存观测快照 |
| SystemUI | `StatusBarAssetsHook` 在顶部状态栏范围发现、观察和覆盖图标/文字，`StatusBarArtwork` 管理独立 drawable 与动画生命周期，既有组件绘制器接入分层素材 |

两个独立配置键为 `ls_augment_statusbar_artwork_v1` 与 `ls_augment_statusbar_fonts_v1`。本页应用原子保存这两个键，布局编辑器不把它们纳入自己的草稿，防止互相覆盖。外部文件选择器返回的资源会复制进应用私有目录，SystemUI 不需要长期访问用户选择的外部 URI。

## 运行边界

目录项目和编辑图样不代表原厂对象当前存在或可替换。没有安全局部绘制入口的复杂容器仅观察，保留绑定配置并恢复原厂；可用子组件仍可独立应用素材。

无素材或字体配置时对应绘制路径快速返回。图片使用控件局部 Drawable，实例及动画按显隐、屏幕状态和数量预算管理；息屏停止高频动画，恢复后读取实际状态。状态未知、素材缺失或组合信息无法可靠表达时保留原厂提示。
