# 红魔Duo v2.0.0-alpha1-test20497

发布日期：2026-10-09。内部版本号：20497。本次为 Alpha 预发布版本，更新范围为 test20496 至 test20497。

## 更新内容

- **日志异常归因**：区分模块自身异常与原调用链异常，保留首次、最近一次错误和发生次数，便于定位问题来源。
- **诊断记录有效性**：结合模块版本、安装身份、目标进程、开机记录和观察时间判断运行记录，避免把旧版本或其他进程的记录当作当前状态；导出日志同步包含归因信息。
- **息屏自动化**：分别记录配置桥接状态与实际执行结果，持久保存请求和结果；执行回执丢失时先查询原请求，避免重复执行。明确失败后按有限次数重试，保留失败历史。
- **状态栏运行清单**：增加上报失败后的重试和重复请求合并，减少配置桥接暂时不可用造成的清单遗漏。
- **游戏运行检查**：连招变速缓存核验原文件时间戳与事件内容，避免复用已经失效的数据；极速连点补充启用、兼容与熔断决策记录。AI 触发器缩小 Handler 钩子作用范围，关闭时快速透传原调用。
- **功能入口整理**：清理旧“亮度与音量”分组，音量百分比在“声音与音量 → 音量面板与按键”直接显示；同步网页预览的分组和入口。
- **源码分发**：排除历史一次性原型修改、截图对照和旧回归安装脚本，保留必要源码、运行资源、构建配置、维护文档及可复用测试。

## 使用条件

- 最低 Android 15（API 35），目标 Android 16（API 36），原生库为 `arm64-v8a`；需要支持 libxposed API 102 的框架，部分功能需要 Root。
- 主要适配基准为 NX809J／RedMagicOS 11.5.7MR1／Android 16，具体功能依赖本机原厂组件和已适配接口。
- 功能由手机端模块及原厂作用域执行，网页预览和电脑开发工具不作为使用前提。
