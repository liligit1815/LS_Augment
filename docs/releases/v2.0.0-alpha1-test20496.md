# 红魔Duo v2.0.0-alpha1-test20496

发布日期：2026-10-09。内部版本号：20496。本次为 Alpha 预发布版本，更新范围为上次公开发布的 test20378 至 test20496。

## 更新内容

- **下拉与状态栏性能**：减少通知中心、控制中心下拉期间的重复图标扫描、文字测量和反射查找；稳定画面复用布局结果，原厂状态与配置变化继续触发刷新。关闭功能时恢复已有修改并停止对应扫描。
- **功能分类与导航**：主页整理为 13 个功能分类，状态栏与灵动岛归入“通知与控制中心”，主题下载与联名主题归入“主题与锁屏”。搜索显示完整路径并直达功能，旧入口继续跳转到新归属，保留已有配置。
- **状态栏自定义**：统一使用组件排列，支持单双排、组件顺序、位置、间距及预设；按桌面与应用、锁屏、通知中心、控制中心分别设置素材、字体和额外隐藏。增加图标间距、通知区域汇总及真实状态素材适配，修复静态信号素材尺寸、拥挤排列回退和时钟几何问题。旧表格入口与输出已移除，旧备份兼容读取。
- **灵动岛**：提供音乐、通知和充电三类实时活动，支持紧凑显示、长按展开、媒体操作和通知来源跳转；空闲、锁屏及息屏时收起，活动结束后按实际状态退出。
- **通知与控制中心外观**：增加通知页大时钟、通知堆叠参数、清除按钮样式及原厂音乐卡片隐藏；支持控制中心圆角、活动磁贴配色与渐变、音乐封面背景及内缘发光。通知页、控制中心和锁屏可独立设置运营商文字。
- **桌面与最近任务**：新增 3～12 行列布局、常用预设和方形布局，保留原厂分页重排及小组件占位保护；改进最近任务内存显示和图标名称编辑。
- **散热风扇**：固定控制统一为一至五档，无需先测量；增强原厂磁贴长按面板的档位选择、显示时机和转速反馈。新增息屏延续运行，保留原厂关闭与保护策略；移除目标 RPM 和最高转速功能。
- **游戏空间**：新增自定义性能监测，可选择时间、FPS、网速、电量和游戏时长，设置 0～100% 背景透明度。普通模块升级保留设备环境未变化的肩键兼容认证，环境或兼容协议变化时重新认证。
- **系统与交互**：新增蓝牙电量图标、游戏登录及第三方跨应用小窗跳转、短信验证码剪贴板、极暗磁贴和完整亮度扩展；修复音量百分比漏显、电源菜单关闭状态及长侧滑自定义背景。
- **配置与维护**：完善备份、导入和全部重置，清理模块素材、名单、绑定及运行记录，恢复具备原值记录的外部修改；贡献名单使用网页内容并保留 APK 内离线快照。

## 使用条件

- 最低 Android 15（API 35），目标 Android 16（API 36），原生库为 `arm64-v8a`；需要支持 libxposed API 102 的框架，部分功能需要 Root。
- 主要适配基准为 NX809J／RedMagicOS 11.5.7MR1／Android 16。风扇固定档位、测量、息屏延续与完整亮度扩展仅对相应接口已适配的 NX809J 开放；具体功能仍依赖本机原厂组件。
- 游戏性能监测适配 GameAssist 17，须先打开原厂“性能监控”插件，数据由原厂插件采集。
- 灵动岛范围为音乐、通知、充电活动。状态栏动态信息继续使用实际系统状态；素材无法表达该状态时保留原厂提示。
- 全部重置只恢复有完整原值及归属记录的外部修改，不回滚健康应用已有步数和云端记录，也不推算缺失的历史原值。
