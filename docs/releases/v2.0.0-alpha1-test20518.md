# 红魔Duo 2.0.0-alpha1-test20518

内部版本号：20518。继承 test20517 的既有功能与修复。

- 主配置界面在前台检查新版本，自动检查在 24 小时内最多尝试一次；无新版或检查失败时保持静默。
- “关于”的当前设备/版本卡片新增“检查更新”按钮，可查看更新说明并确认下载。
- 通过公开的 `liligit1815/lispacerelease` 仓库读取红魔 Duo 专属清单，安装包使用 GitHub Release 附件。
- 软件内下载展示进度并支持取消；下载完成后校验长度、SHA-256、包名、版本、最低系统版本和兼容签名，再交给系统安装界面确认。
- 安装来源尚未允许时提供系统授权入口，返回后再次验证安装包；旋转保留检查/下载状态，避免重复下载或自动重复打开安装界面。
- 修正并更新联网与隐私说明，新版说明需在配置界面确认。

验证：原发行签名构建、上一版 APK 版本递增/签名核对、ZIP 对齐与清单/下载 URL/签名关系的主机测试。当前未连接 Android 设备，未进行真机截图、下载与系统安装验收。

`tools/test-app-updates.py` 的 54 项协议与安全检查通过；Release 构建及 `lintVitalRelease` 通过。全量 `lintRelease` 报告 13 项既有代码或本地配置错误，均不在新增更新类中，本版未修改这些无关部分。
