# 红魔Duo v2.0.0-alpha1-test20378

发布日期：2026-09-28。内部版本号：20378。此版本为 Alpha 测试版，更新范围为上次公开发布的 test20357 至 test20378。

## 更新内容

- **品牌与联名定制**：应用及模块统一为“红魔Duo”，兼容旧配置；新增联名主题、指纹样式、充电动画及本机联名音频导入。独立“臻金 · GOLDEN SAGA”放在原厂“焰旋流光”之前，保留原厂条目、独立编号及已保存的选择。
- **侧滑返回自定义**：左右侧独立选择图标和背景，支持 GIF、动态 WebP、10%–1000% 缩放、透明度、镜像、位置调整、双侧复制及单侧恢复；内置初音未来预设，自定义资源随配置备份。
- **桌面页面管理**：重构“页面”入口和编辑界面，支持页面预览、点选移动、长按拖动及空白页管理；修复连续新增页面编号冲突，增加防连点、取消及失败回滚。
- **最近任务清理特效**：增加爆炸声光与晶片解构两种效果。爆炸包含白热闪光、动态火球、烟尘、火星与原创爆破音；晶片解构包含青紫光束及发光碎片。保留原厂锁定任务和清理规则，修复清理黑屏、按钮刷新及自定义图标类型转换问题。音效遵循系统音量与响铃模式，振动或静音时不强制播放。
- **高级重启菜单**：加入四种高级重启模式，统一按钮布局、入场动画与模式图标，修复确认页按钮残留和入口未注册；通过模块 Root 通道执行。
- **状态栏与通知**：修正最近任务中自定义时钟缺字、散热图标隐藏及额外裁剪；按参考素材调整双排信号的圆点、胶囊柱条与比例；修正音量百分比重复显示，增加可展开、收起及滑动清除的通知堆叠。
- **液态玻璃候选功能**：控制中心与系统桌面 Dock 可分别启用，保留原厂前景及交互；控件独立材质、顶部宽按钮、原厂圆角与 Dock 范围适配，增加减少透明／动态选项，后景不可用时回退半透明效果。
- **兼容与维护**：修正全应用肩键及连招资格，保留原厂按应用开关；增加健康使用手机入口、未成年人模式桌面图标隐藏及空位释放；扩展桌面退出、崩溃、图形与清理阶段诊断，补充红魔水印字数解限。

## 使用条件与验证范围

- 最低 Android 15（API 35），目标 Android 16（API 36），原生库为 arm64-v8a；需要支持 libxposed API 102 的框架，部分功能需要 Root。
- 本次发布重新执行了 Release 构建、125 组项目检查（0 失败）和完整 Java／运行时回归；APK 签名及 16 KB 对齐检查通过。未在本次发布流程中重新执行真机操作或全量 lint。
- 既有 NX809J / RedMagicOS 11.5.7MR1 / Android 16 实测记录覆盖清理动画、菜单主要交互、独立指纹保存及最新指纹列表排序；这不等于所有设备和全部功能均已验证。
- 双 SIM 显示、真实手指解锁、其他机型以及液态玻璃的真机视觉／GPU 效果仍需进一步验收。主题、指纹与充电动画依赖本机原厂资源，资源或接口不可用时会回退。
