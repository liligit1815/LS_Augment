# 红魔Duo v2.0.0-alpha1-test20509

发布日期：2026-10-10。内部版本号：20509。Alpha 预发布。本次汇总自上一公开版本 test20505 以来的更新。

## 更新内容

- **灵动岛新增圆形样式**：“通知与控制中心 → 灵动岛”新增“灵动岛app显示样式”，提供“圆角方形”和“圆形”。紧凑态与展开详情中的应用图标、音乐封面同步使用所选样式；默认圆角方形，关闭灵动岛后保留选择。
- **统一灵动岛设置界面**：样式功能行、展开参数、选择按钮与选项弹窗使用红魔Duo公共组件，统一字号、间距、对齐及玻璃质感。
- **关于页显示模块版本**：“关于 → 当前设备”卡片新增第四行“红魔Duo版本”，显示当前安装包的完整版本名称，便于确认已安装版本。
- **修复状态栏布局恢复**：布局空间不足时隐藏遗留自定义内容并回退原厂显示；空间恢复且布局成功后及时恢复自定义内容、清除旧错误状态，避免残留遮挡与延迟恢复。
- **改善风扇启动控制**：启动时转速读数尚未有效，会在限定时间内等待连续有效读数后接管；等待期间不写入硬件控制，运行中的异常仍触发保护与原厂回退。
- **修复息屏自动化恢复**：配置暂时不可用或设备尚未解锁时保留重试，恢复后重新读取；亮屏刷新配置不会触发息屏动作。结果不确定的操作查询原请求，避免重复执行。
- **完善日志与运行诊断**：补全同一进程的多包归属，按当前版本、进程和本次开机信息补充运行状态；区分日志读取失败、空输入与无匹配，标记内容截断，完善手动重启操作及日志写入失败的记录。

## 安装与生效

1. 建议先通过模块备份功能导出当前配置。
2. 下载 `RedMagicDuo-v2.0.0-alpha1-test20509-release.apk` 并覆盖安装。本版沿用现有发布签名。
3. 在支持 libxposed API 102 的框架中启用模块及所需作用域，按页面提示重启相关应用、系统界面或设备，使对应进程加载新版功能。
4. 重新打开“关于 → 当前设备”，可查看“红魔Duo版本”；灵动岛样式在“通知与控制中心 → 灵动岛”选择。

最低 Android 15，原生库为 `arm64-v8a`。部分功能需要 Root；风扇控制等硬件功能遵循已适配设备与原厂接口的可用范围。
