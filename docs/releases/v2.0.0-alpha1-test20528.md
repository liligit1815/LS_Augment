# 红魔Duo 2.0.0-alpha1-test20528

本版修复双排信号颜色与流量箭头位置，更新通知堆叠操作，并修复下拉通知中心时日期与通知卡片间距抖动。

## 双排信号

- 修复深浅背景下信号颜色与原厂图标不一致的问题。颜色随信号所在区域同步更新，自定义排列与原厂排列均适用。
- 固定 SIM1 上排、SIM2 下排，切换流量卡时不交换两排。流量箭头跟随实际活动数据卡，SIM1 在上、SIM2 在下。
- 信号强度、网络类型、HD 和素材保持对应实际卡槽；三合一圆环继续按流量卡与另一张卡选择内容。

## 通知堆叠

通知堆叠总开关只控制功能启用，大、小堆叠独立设置，可以同时开启。总开关开启后的组合如下：

| 大堆叠 | 小堆叠 | 展示方式 |
|---|---|---|
| 关闭 | 关闭 | 保持原厂通知列表 |
| 关闭 | 开启 | 在通知、静默各自分类内按同应用堆叠 |
| 开启 | 关闭 | 通知与静默合为大堆叠，展开后逐条显示 |
| 开启 | 开启 | 先展开大堆叠，再按需展开同应用小堆叠 |

- 取消模块展开箭头，点击收起状态的首张通知卡片展开，一次只展开当前层。这次点击不同时打开通知，展开后恢复原厂点击操作。
- 大堆叠优先显示通知区域最新一条；仅有静默通知时显示最新静默通知。小堆叠按应用和用户区分。
- 适配国内固件关闭原厂通知分区的情况，复用原厂静默与最小化判定，保留静默标题、原生通知组、频道重要性与清除规则。
- 三个开关默认关闭。关闭总开关保留子项设置，升级不自动开启新模式；关闭通知栏后堆叠恢复收起。

## 通知中心间距

修复下拉后日期与首张通知卡片间距先抖动、再恢复的问题。时钟秒数、中文时段或大时钟参与布局时，按当前日期区域分配留白，避免原厂动画位移重复计算及旧间距覆盖新布局；通知堆叠关闭时同样适用。原厂入场、回弹、侧滑与清除动画继续保留。

## 更新操作

可通过“关于 → 检查更新”使用原发行签名覆盖安装。安装后通过“重启作用域 → 状态栏（SystemUI）”加载新实现，原有配置继续保留。
