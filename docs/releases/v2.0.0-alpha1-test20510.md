# 红魔Duo v2.0.0-alpha1-test20510

发布日期：2026-10-10。内部版本号：20510。

## 更新内容

- **新增锁屏上滑效果**：在“主页 → 主题与锁屏 → 锁屏上滑效果”配置底部指示条、触感反馈、内容联动、松手回弹、快速上甩、弧形边界、背景模糊、锁屏玻璃和提示文字。基于 LiftArc 整合到红魔Duo，由手机端系统界面作用域执行；解锁继续遵循系统安全规则。
- **统一配置管理**：锁屏上滑效果的全部 39 项配置纳入现有导入、导出和全局重置。关闭功能保留参数。
- **纳入现有日志体系**：锁屏上滑效果的运行记录、异常和适配状态进入模块日志，支持现有查看、复制、清空、分享及统一导出，无需额外日志开关。
- **复用作用域重启入口**：功能页顶部使用现有“重启作用域”弹窗，通过“状态栏（SystemUI）”重启锁屏功能所属进程。
- **精简锁屏配置界面**：22 项数值设置统一使用滑动条和实时数值，移除重复输入框及本页恢复默认值按钮；保留文字、颜色和选项编辑，统一公共控件、字号与间距。
- **更新贡献名单网页**：新增“感谢”说明，展示 HyperCeiler、LiftArc、红魔助手及原始项目图标；HyperCeiler 和 LiftArc 可点击跳转 GitHub。移除原贡献者栏目、名单和项目描述，加大加粗“感谢”“捐赠列表”标题。
- **保留网页在线更新与离线显示**：贡献名单继续使用网页，构建时取得正式网页作为离线内容，打开时自动获取最新页面；图标内联，无需额外图片请求。

## 安装

1. 可先通过模块配置管理导出当前配置。
2. 下载 `RedMagicDuo-v2.0.0-alpha1-test20510-release.apk` 并覆盖安装。本版沿用现有发布签名。
3. 在支持 libxposed API 102 的框架中启用模块及所需作用域，按页面提示重启相关应用、系统界面或设备。
4. 锁屏上滑效果默认关闭，请在对应功能页按需开启。

最低 Android 15，原生库为 `arm64-v8a`。部分功能需要 Root，并受设备原厂接口及适配范围限制。
