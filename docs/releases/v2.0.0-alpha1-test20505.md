# 红魔Duo v2.0.0-alpha1-test20505

发布日期：2026-10-09。内部版本号：20505。本次为 Alpha 预发布版本，更新范围为 test20497 至 test20505。

## 更新内容

- **第三方桌面最近任务**：“桌面与最近任务 → 默认桌面”新增独立开关“禁用第三方桌面最近任务遮罩”，默认关闭。开启后移除系统独立最近任务的纯白或纯黑背景遮罩，显示壁纸；关闭后恢复原厂遮罩，下次进入最近任务生效。此功能需启用系统桌面作用域，与“允许设置第三方默认桌面”开关独立。
- **灵动岛媒体显示**：媒体来源处于前台时自动收起，切到后台且仍在播放时恢复，应用切换时及时更新。视频媒体会话遵循同样规则，同名应用的其他用户或分身独立识别。
- **灵动岛外观**：新增上下偏移，范围 −24～24dp，实际位置限制在状态栏内；新增透明样式，可去掉紧凑胶囊的黑色背景，保留活动图标、文字与律动，展开详情保持原有背景。
- **VPN 图标**：新增圆环样式，与蓝牙电量圆环共用矢量绘制并跟随系统状态栏颜色。沿用原生 VPN 显示、隐藏及溢出规则，不改变连接状态。
- **图标样式选择与刷新**：蓝牙和 VPN 选择项提供样式示例；切换样式时原位更新图标及占用空间，保留其他状态栏内容与三合一运行状态。“原生简洁”预设同步恢复原厂 VPN 样式。
- **设置界面**：统一状态栏时钟、通知图标、实时指标、电池与三合一、系统图标等页面的功能行、折叠项、分割线及参数间距，清理重复摘要。公共选择弹窗跟随当前页面的状态栏与导航栏明暗外观。

## 使用条件

- 最低 Android 15（API 35），目标 Android 16（API 36），原生库为 `arm64-v8a`；需要支持 libxposed API 102 的框架，部分功能需要 Root。
- 主要适配基准为 NX809J／RedMagicOS 11.5.7MR1／Android 16，具体功能依赖本机原厂组件和已适配接口。
- 功能由手机端模块及原厂作用域执行，电脑开发工具和网页预览不作为使用前提。
- 已绑定的 VPN 素材优先显示。使用内置圆环前，请在 VPN 素材设置中清除绑定并应用，素材文件保留。“仅调整位置和大小”模式保留原厂图标样式。
