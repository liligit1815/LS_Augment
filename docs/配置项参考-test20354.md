# 通用配置项参考 · test20354

版本：`2.0.0-alpha1-test20354`。整理日期：2026-09-23。

本表编译并读取当前 `EnhancementCatalog`、五组 `*Options` 和 `HookAppCatalog` 得到，展开了源码中的循环定义，共 **216 项**：204 项应用通用配置、5 项模块外观保留配置、7 项内部兼容字段。它不是所有 `ConfigSchema` 字段清单，也不是独立功能数量。肩键、隐藏名单、状态栏布局和健康计划等专用字段见[功能说明](最新版功能说明.md)。

表中的默认值来自选项定义，不代表用户设备当前保存值。开关 `0` 为关、`1` 为开；选择项按 0 起始索引保存。子参数还受所属功能开关影响；有效范围不意味着该设备已支持。内部字段不供手动开关，外观字段当前没有全部出现在设置主页。
