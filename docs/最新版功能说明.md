# LS_Augment 最新版功能说明

版本：**2.0.0-alpha1-test20354 / 20354**。整理日期：2026-09-23。

依据当前 Android 源码、配置校验、导航和 Hook 实现整理，描述代码能力与页面行为，不把旧截图、版本匹配或源码存在当作真机验收。精简后的历史文档已不存在，本文不沿用失效的逐版本验收链接。

## 入口与配置范围

底部为主页、设置、关于。主页按负责功能的应用分为 **18 类**，支持搜索；普通功能按开关和展开参数呈现，复杂能力使用专用编辑器。

当前通用目录有 **216 项定义：204 项应用配置、5 项保留的模块外观配置、7 项内部兼容字段**。参数、颜色和开关分别计数，不等于独立功能数量；状态栏布局、肩键测试、隐藏名单和健康计划还有专用配置。见[配置项参考](配置项参考-test20354.md)。

有效修改通常自动保存，输入无效时保留上次有效值。按页面提示重启作用域。关闭功能通常保留参数，但不会自动撤回已隐藏应用或已经写入的步数。

## test20354 电池显示规则

入口：系统界面 → 编辑状态栏 → 电池。

| 三合一 | 原生电池增强 | 行为 |
|---|---|---|
| 关闭 | 关闭 | 恢复默认电池外观与布局，仍跟随状态栏整体布局 |
| 开启 | 关闭 | 使用三合一图标与高级参数 |
| 关闭 | 开启 | 使用原生电池自定义样式、位置和大小 |
| 尝试同时开启 | — | 开启后一项时自动关闭前一项 |

关闭一项不会自动开启另一项，两边参数保留。“仅调整位置和大小”模式使用原生外观，暂停三合一但不清除配置。

## 系统框架

### 小窗与系统行为

- 解除小窗数量上限，允许创建和最小化超过三个自由窗口；向普通应用开放小窗，提供“遵循原厂小窗应用”例外名单，保留关键系统界面保护。
- 允许受限窗口截图／录屏；是否隐藏捕获画面的状态栏另行配置。
- 取消每 72 小时强制验证密码，开机首次解锁仍遵循原厂规则。
- 自定义锁屏息屏等待时间 1–86400 秒；亮屏解锁时通知静音；隐藏悬浮窗常驻提示。
- 取消已适配的打开方式劫持、允许被悬浮窗遮挡的触摸、关闭已识别原厂统计服务初始化。
- 长按电源的助理动作使用系统默认数字助理，保留原厂关机菜单选择。

### 音量规则与增强

| 设置 | 范围与行为 |
|---|---|
| 基础档数 | 闹钟、媒体、通知、铃声、通话分别设 1–200 档；修改后重启手机 |
| 额外增益 | 扬声器、有线／USB 耳机、蓝牙分别配置媒体、铃声、闹钟上限，100%–300% |
| 增强步长 | 达到原厂上限后，每按一次加键增加 1–20 个百分点 |
| 不追加增强 | 上限 100%、关闭增益，或通知／通话类型 |
| 其他 | 取消音量过高提示；锁屏调音量和长按音量键振动在系统界面分类 |

例：基础 15 档，上限 150%，增强步长 10%，额外 5 档，面板总计 20 档。百分比是软件增益，不是实测响度同比提升；实际可用效果取决于音频通道。

### 安装与无线连接

- 同包名不同签名覆盖安装：原校验先执行，再针对签名不一致更新失败处理。覆盖后的应用能访问原数据，仅用于可信 APK。
- 放宽较旧 APK 签名方案要求，与不同签名覆盖分别控制。
- 飞行模式保留蓝牙或 Wi-Fi／热点；两位 Wi-Fi 国家码；固定 Wi-Fi MAC、热点 BSSID。地址做有效性校验，空白不修改。

## 系统界面

### 状态栏编辑器

六个分类：**布局、时钟、通知、硬件网速、图标、电池**。顶部是可点选的示例预览，不是手机实时截图。

- 组件区域、顺序、大小和位置；前后移动、排序、自动整理与避让；单排／双排布局。
- 三种布局预设先预览，确认才保存；取消或离开恢复预览前状态。可恢复最近一次整理、预设或整体重置前的编辑器配置。
- 高度、四边留白、两排间距；间距 -8～8 dp，负值遇到碰撞时按安全间距显示。
- “仅调整位置和大小”保留原生行数、字体、图标样式，暂停自定义时钟、双排图标、硬件信息和自定义网速。
- 无法识别原厂结构或出现异常时回退，并清理遗留自定义层。

### 时钟、通知与系统图标

- 时钟单排／双排、独立行格式、秒、星期、12／24 小时制、时段、字号、字重、字距、宽度和对齐。
- 农历、干支、生肖、节气、时辰扩展格式。离线数据已编入源码，覆盖香港天文台 1901–2100 年历表；`y` 为公历年、`Y` 为农历干支年，固定文字用单引号。
- 毫秒刷新 16–1000 ms，配合格式 `S`，息屏暂停高频刷新。
- 通知数量、双排和原生通知图标；隐藏显示不删除通知。
- 系统图标双排、双卡信号上下排列；隐藏 Wi-Fi 箭头／标准数字、移动数据箭头／类型、大小 HD、各 SIM 信号、隐私绿点。
- Wi-Fi、热点、移动网络可按主屏、锁屏、通知栏头部、合并／独立控制中心隐藏；支持其他图标槽位名单和忽略原厂隐藏限制。
- 双击状态栏锁屏、隐藏状态栏内容、恢复原生字体、挖孔黑圈常显。

### 温度、功率和网速

- CPU、GPU、电池温度、电流、功率独立位置、大小、顺序、前缀、宽度及 0–3 位小数；支持隐藏单位、仅充电显示电流和功率。
- 读取设备实际可用传感器，不把温控阈值当成测量结果。
- 自定义网速上下行组合、单双排、上传／下载标志，标志可以留空；低速隐藏阈值、有效位数、自动／固定单位、`/s` 与固定宽度。
- 原生网速字号独立配置；先在系统中开启原生网速，0 表示跟随系统。

### 三合一与原生电池

- 外圈表示电量；内部上方、中部、下方分别选择电量数字、Wi-Fi、双卡、流量卡、另一张卡或不显示。
- 每区域独立移动 -100%～100% 图标直径、缩放 50%～300%，隐藏内容时仍保留参数。
- 普通充电闪电、旁路充电插头分别移动和缩放，共用自定义颜色；默认跟随电量数字，没有电量数字时不显示附属标志。
- 未充电／普通充电／旁路充电预览；圆环粗细、未点亮不透明度、低电量与充电颜色；电量字体颜色另设。
- 原生电池可选数字位置、仅图形／数字或隐藏，设置百分号、固定宽度、不透明度和颜色，集中于折叠卡片。

### 控制中心与通知天气

- 亮度、音量滑杆分别显示整数百分比，按原生滑杆当前范围计算。
- 普通磁贴横竖屏行列、编辑页列数；保留原生滚动／分页。
- 运营商名称、搜索按钮显示控制；指定搜索按钮打开的已安装应用；日期打开默认日历；面板时钟秒数与中文时段。
- 通知中心日期右侧显示地区、天气和摄氏温度，点击进入原厂天气。先在原厂天气设城市并更新；不是模块联网取得独立天气源。
- 风扇详情中的固定档位见散热风扇说明。

### 锁屏、息屏与交互

- 隐藏锁屏顶部状态栏；文字大时钟秒数、中文时段、导入／恢复字体、0.5–2 倍比例及空间适配。
- 自定义充电动画：持续 1–120 秒、延迟 0–60 秒、每次亮屏播放。
- 锁屏充电详情：温度、电流、电压、功率各项隐藏，字号、间距、刷新周期。
- 息屏时钟秒数、中文时段、字体、比例和时段字号。文字、斜切、翻转分层数字分别适配；艺术数字、日历翻页和表盘并非都支持。
- 锁屏允许调音量、取消长按音量键振动、原生剪贴板浮窗、单手模式位置、默认数字助理手势。
- 自动允许 USB 调试授权，仅在确实需要自动接受该授权行为时启用。

## 系统设置

- 扩展原厂自动息屏时间选项，隐藏系统电量百分比设置入口，时间选择器显示中文时段。
- USB 安装免账号验证；默认用途：仅充电、文件传输、照片传输、多屏投屏。
- 连接时用途弹窗与通知选择入口控制；隐藏通知入口依赖对应父开关。
- 直接修改原厂开发者选项、USB 调试、USB 安装、锁定刷新率四项开关。旧“打开开发者设置”跳转按钮已移除，不等于这些开关被移除。

## 系统桌面

- 按用户空间和应用设置图标、名称，支持图片选择、裁剪、恢复；不改变 APK 签名。
- 编辑预览中长按整页排序，图标、文件夹、组件随页移动；新增／删除并保留空白页。
- 支持原厂及指定 260005 修改版桌面的相关结构；桌面时钟自定义格式和中文时段。
- 最近任务内存：开关、简洁／详细样式、可用／已用／总量组合、字号、深浅颜色、横竖屏位置和区域高度。使用实际物理内存，不改任务卡片布局。
- 修改版桌面检查位于日志及运行诊断，仅读取兼容信息，不安装桌面。独立桌面源码和 APK 不在当前项目。

## 游戏与 AI 触发器

- 全应用肩键：向加入游戏空间的应用开放原厂肩键。
- 极速连点 **10–50 次／秒**，按住触发、松开停止。测试核验 Root、目标组件、系统层与原生库，再分别采集左右实体键，验证实际节拍、松开停止和稳定性。通过只解锁开关；模块或设备变化可能要求重测。
- 肩键方案快捷切换：原厂页勾选参与方案，一个直接应用、两个互切、多个下拉选择。
- 连招 **1–10 倍**播放，保留原始录制，下次播放使用新倍率；循环次数可输入六位数，间隔最长一小时。
- 向其他性能模式开放原厂超分，阻止超分与破坏神自动互斥，保留主动关闭。
- 隐藏破坏神提示、切换模式保留面板、按游戏记住活跃模式。
- 原厂插件资格、高光、随心录制、红魔时刻的已适配限制；原始、4:3、16:9、21:9、32:9 比例。
- AI 参数：模板扫描 80–2000 ms、点击队列 10–500 ms、策略冷却 50–2000 ms、YOLO 扫描 150–1500 ms。实际触发仍受识图、模型和点击耗时影响，首次启用按提示重启游戏作用域。

## 散热风扇

- 固定方式可选目标 RPM 或一至五档，跟随原厂开关，不自行启动风扇。
- RPM 根据本机逐档测量匹配最近硬件档位，不是无级调速；完成／取消测量恢复原厂控制。
- NX809J 控制中心详情可在均衡散热、疾速散热、固定档位间切换；固定档位展开一至五档拖动及档位／转速反馈。当前不支持第六档。
- NX769J 仅适配原厂全速接口，定速、逐档测量和反馈仍待实机验证，不借用其他型号的指令。
- 原厂最高转速能力不意味着突破硬件极限，可用性以设备接口为准。

## 小米运动健康

- 先打开健康应用等待账户接入，再绑定当前本机账户；换账户后重新绑定。
- 真实步数 **1–10 倍**计入新记录，计划增加的步数不再乘倍数。
- 随机增步设置时间范围、星期、次数和每次步数；每天 1–100 次、不同分钟执行，每日计划总量不超过 1,000,000 步。
- 支持跨午夜，星期归开始当天；当日已经生成的随机时间表保持稳定，修改用于下一执行日。
- 当日上限 1–1,000,000 步，仅停止额外新增；真实步行继续、不减少已有记录，提高／关闭上限不补发先前受限步数。
- 后台需允许健康应用自启动和后台运行；强行停止后重新打开。同步走健康应用，关闭计划不回滚已存步数。

## 消失吧APP

在“关于”的“系统版本”连续点七次，相邻点击间隔不超过两秒。返回主页且搜索为空时出现入口；离开应用前台后重新锁定，已隐藏应用不会因此自动显示。

- 按空间选应用，支持全部空间、名称／包名搜索、名称／安装时间排序、刷新、自动保存勾选。
- 全部隐藏／显示操作各空间已保存名单，显示执行与核验结果。
- 取消勾选只改名单；关闭应用隐藏也不自动显示，仍可展开手动显示。
- 自动隐藏实际由系统亮到灭事件触发，每次最多执行一次，可选当前或所有已配置空间；解锁不自动显示。
- 磁贴自定义图片、名称、说明；混合状态优先全部显示，关闭动作后留在面板但不操作应用。
- 空间身份不明、名单异常、环境不满足时保留记录并提示，不把未知用户当成用户 0。
- 历史恢复和事务类仍在源码中，但当前 Manifest 未注册 `HideRecoveryActivity`，页面也无旧“应用显示与历史”入口，不能当作当前可访问功能。

## 模块维护、外观与退出的旧功能

- 设置页隐藏／恢复模块桌面入口，隐藏后可从框架模块设置进入。
- 配置备份包括功能设置、应用选择、图片、字体、肩键候选，文档最大 32 MiB。排除账户绑定、步数起点、肩键兼容令牌／会话、风扇测量请求／结果及运行诊断。
- 导入完整校验并确认；恢复默认不等于撤销已经执行的应用隐藏等持久结果。
- 诊断菜单分框架、当前版本、修改版桌面、日志；进入不自动开启日志或重启。排查顺序：开详细诊断 → 重启作用域 → 复现 → 导出。
- 源码保留浅色／深色／随系统、背景模糊、遮罩、宽屏双栏五项外观配置，**当前设置主页未提供全部旧外观入口**；字段存在不代表页面有对应按钮。
- 关于包含本地设备信息、贡献者、支持图片、使用说明。模块不申请网络权限。
- 电池老化电压策略退出当前产品入口；`BatteryLifeControl` 仅做旧覆盖清理，旧 `battery` 页面直接退出。
- 独立修改版桌面不在本项目构建范围。网页原型仍为 test20288，样例按钮和读数不代表手机执行结果。
