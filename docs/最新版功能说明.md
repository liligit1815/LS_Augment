# 最新版功能说明

当前源码版本以 [android/version.properties](../android/version.properties) 为准，最近发布记录见[20690 说明](releases/v2.0.0-alpha1-test20690.md)。各功能按运行时类、方法签名、字段类型和原厂资源选择适配路径；已支持的旧接口继续保留，未知结构保持原生行为并说明缺失能力。新增接口适配不代表所有机型和应用均可用。

模块配置、缓存和恢复记录统一使用应用私有存储，保留 LSPosed 官方配置副本。旧数据确认保存完整后才清理；未知数据、活跃旧写入者和未完成的恢复责任继续保留。当前数据归属及迁移规则见[模块私有存储](模块私有存储.md)。

红魔Duo 的功能由手机端模块、Root 通道和对应原厂作用域执行。主页按任务分为 14 类：通知与控制中心、桌面与最近任务、主题与锁屏、声音与音量、操作与手势、小窗与多任务、红魔Step、相册与编辑、游戏空间、散热风扇、网络与连接、应用管理、系统设置、小米运动健康。状态栏自定义和灵动岛位于“通知与控制中心”，主题下载与联名主题位于“主题与锁屏”。

当前功能包括状态栏组件排列与四位置素材字体、灵动岛实时活动、通知与控制中心外观、锁屏上滑效果、桌面行列、风扇五档与息屏延续、游戏性能监测、跨应用小窗、配置备份与全部重置。“关于 → 当前设备”显示设备型号、系统版本、Android 版本及实际安装的红魔Duo版本。双排信号固定物理 SIM 顺序，流量箭头跟随实际数据卡，颜色随原厂所在区域更新，三合一圆环保留数据卡角色。通知堆叠将同应用通知组中的真实子通知分别显示为渐进卡片，通知中心和锁屏独立配置，支持模糊与透明度渐变，关闭后恢复原厂分组。通知留白修复适用于时钟格式布局，通知堆叠关闭时同样生效；原厂动画与通知操作保留，状态栏空间不足仍按原规则回退单排。

## 入口与配置范围

底部为主页、模块、关于。主页搜索入口打开独立搜索页，支持近期搜索记录；搜索功能名称，结果显示所属分类和完整路径，点击直达并定位功能项；旧分类和分组链接继续跳转到当前归属。普通功能使用开关与独立展开参数，复杂能力使用专用编辑器。

展开后的标题、摘要和配置内容使用连续的分组背景、边界与层级引导，便于辨认所属功能。数值参数合并显示名称、当前值和帮助入口，点按名称或数值可精确输入；数值范围、步长与滑条一致。滑条显示行默认 20dp，普通连续滑条参数之间保留 4dp 间隔，长标题、大字号和原生滑块较高时按实际内容扩展；周围空白支持拖动，已有帮助与数值点击区域保持优先。

配置键、参数、颜色和开关不等于独立功能数量。状态栏布局、肩键测试、隐藏名单和健康计划另有专用配置；通用字段、默认值与取值范围以当前[配置定义](../android/app/src/main/java/ls/augment/com/ConfigSchema.java)为准，锁屏上滑的 39 项配置见 [LiftArcOptions](../android/app/src/main/java/ls/augment/com/LiftArcOptions.java)。

有效修改通常自动保存，输入无效时保留上次有效值；素材与字体使用草稿，点击“应用”后保存。关闭功能通常保留参数，不自动回滚已经写入的步数或已经执行的应用隐藏。按页面提示重启作用域。

## 系统界面与原厂功能适配

- 自定义控制中心行列仅覆盖普通磁贴，宽磁贴和其他共用尺寸调用保留原厂值；滚动高度不再使用随自身收缩的父容器作为上限。布局回调异常后撤销当前视图的修改并记录缺失能力。
- 主题无限期使用按完整的恢复、试用标记与主动应用方法组选择适配，支持已检查的新旧适配器结构；用户主动更换资源仍走原厂流程。
- 新版桌面的清理动画从原厂批量清理选中的卡片采集，动画结束或退出时再完成原厂监听器，保留锁定任务和原厂清理规则。新版隐私屏通过缩略图自身的绘制覆盖层显示遮罩，兼顾复用、关闭恢复和旧绘制路径。
- 声音与音量 → 音量调节位置：新增“多应用声音与音量调节归为同侧”，配置“音量调节显示位置”为左侧或右侧。前提是系统已开启多应用音量调节；将原厂按钮放到静音按钮下方，沿用原厂显示条件、点击和超时逻辑；圆形按钮大小与静音按钮一致，两段间距相等；按钮完成定位后直接显示，不沿途滑动，展开后的多应用音量面板也遵循所选侧边。横屏可用高度不足以容纳面板和按钮时保留原厂位置，避免遮挡或移出屏幕。
- 锁屏无通知诊断包含系统锁屏通知开关、隐私设置、勿扰状态和原生通知行数量；不强制显示被原厂隐私策略隐藏的通知。

## 红魔Step

首次开启且系统手势接入就绪后，在公共背景的全屏练习界面中，用细边缘标记和单侧滑动动画标明实际触发区域，引导用户从状态栏下方的右上角向左滑，或从左上角向右滑。只有完成手势并真正进入红魔Step后才记录引导完成；可选择“稍后练习”，也可从“打开方式”中的“练习进入手势”重新练习。起滑区域和距离共用实际手势参数，取消或旋转不视为完成。

配置入口：主页 → 红魔Step。由手机模块、Root 及系统框架／系统桌面作用域执行，更新系统接入后需重启手机。前提检查通过才允许开启，关闭保留参数。全局手势从状态栏下方的左／右上侧触发区域起滑，单指向屏幕中间水平滑动后松手，进入独立工作台；可核实的前台任务按原任务接入，从桌面进入或点击“桌面”时借入原生 HOME。

当前运行协议使用四个窗口身份，支持主侧交换、主区全屏及任务恢复。空白侧格可设为 0–3，已有侧窗继续显示。更多窗口、双主区、完整原生最近任务与任意中断后的自动恢复不属于当前完整可用能力；内部扩展模型不等于运行窗口已扩容。

“应用列表显示”管理当前用户真实可启动的桌面入口，支持名称／包名搜索、已选／未选分组、全选反选、隐藏恢复、拖序、置顶及中文首字母定位。隐藏入口不结束已有任务。“应用列表排序”提供手动、使用频率或首字母模式；使用频率读取系统最近 14 天前台进入事件，无权限或读取失败时仅降级本次显示，不改写保存的模式。工作台关闭时仍可管理列表。配置备份版本 2 包含这些偏好，旧版本 1 导入保留当前列表设置。

顶栏根据真实媒体会话、导航来源和持续通知显示状态卡。音乐控制按播放器能力提供；导航结束、过期或用户变化撤销旧内容。通知动作仅转发来源已发布的广播／服务动作，需要输入文字或 Activity 型通知动作时提示限制。派发成功不代表来源操作完成，不确定结果不自动重发。

“工作台设置 → 文字工具”提供文字分词、复制、搜索与分享。工作台文件流转及应用原始内容的跨应用拖拽接入已取消，QQ 不再列入模块作用域；更新后请在 LSP 框架中取消勾选 QQ，并重启手机。已有本地素材缓存按原有效期清理。

退出和中断恢复核验原任务、显示及 HOME 对象身份，失败时保留恢复责任；不保证还原任意原分屏、边界和任务层级。全部功能由手机执行，电脑工具仅用于开发、构建和验证。

“关于 → 许可和第三方声明”提供本地许可、来源目录及完整正文，读取失败可重试。第三方使用范围以对应许可为准；阅读页不替代整体发行与素材授权核定。

## 状态栏时间格式

在通知与控制中心 → 状态栏自定义 → 时钟 → 自定义时钟文字 → 高级：自定义时间格式中，点击“查看完整时间格式与示例”。按时间、日期与星期、时区、农历干支与节气分类，包含大小写区别、重复字母、引号转义、双排和刷新规则；可长按复制格式。示例由实际格式解析器按本机语言和时区生成，系统额外支持的 c、b、B 也会按本机能力列出。旧版时钟编辑入口共用同一份说明。

## 电池显示规则

当前入口：通知与控制中心 → 状态栏自定义 → 电池与三合一。

| 三合一 | 原生电池增强 | 行为 |
|---|---|---|
| 关闭 | 关闭 | 恢复默认电池外观与布局，仍跟随状态栏整体布局 |
| 开启 | 关闭 | 使用三合一图标与高级参数 |
| 关闭 | 开启 | 使用原生电池自定义样式、位置和大小 |
| 尝试同时开启 | — | 开启后一项时自动关闭前一项 |

关闭一项不会自动开启另一项，两边参数保留。“仅调整位置和大小”模式使用原生外观，暂停三合一但不清除配置。

## 小窗与系统规则

### 小窗与系统行为

- “小窗与多任务”分为“跨应用跳转”和“数量与应用范围”，提供对所有应用生效的登录跳转、第三方应用跳转、解除数量上限和全应用支持。登录跳转不再配置游戏名单；原厂小窗例外名单在对应功能下展开。
- 解除小窗数量上限，允许创建和最小化超过三个自由窗口；向普通应用开放小窗，提供“遵循原厂小窗应用”例外名单，保留关键系统界面保护。
- 允许受限窗口截图／录屏；是否隐藏捕获画面的状态栏另行配置。
- 取消每 72 小时强制验证密码，开机首次解锁仍遵循原厂规则。
- 自定义锁屏息屏等待时间 1–86400 秒；亮屏解锁时通知静音；隐藏悬浮窗常驻提示。
- 短信验证码自动加入剪贴板：在「操作与手势 → 剪贴板」开启后，合并新收到的长短信，提取明确标注的 4～8 位数字或字母数字验证码，供当前用户的输入法粘贴。默认关闭；不读取历史短信，不保存或记录正文与验证码；识别不明确时保留原剪贴板。候选提示由输入法自身设置决定。安装新版后需重启手机，之后开关可直接生效。
- 取消已适配的打开方式劫持、允许被悬浮窗遮挡的触摸、关闭已识别原厂统计服务初始化。
- 长按电源的助理动作使用系统默认数字助理，保留原厂关机菜单选择。

## 相册与编辑

- “相册与编辑 → 相册 → 相册水印自定义”支持替换原厂图片编辑器水印中的机型文字，最多 80 个字符；关闭或留空恢复原厂文字。修改后重新进入原厂编辑或水印预览。图片图标、模板位置、文字大小及拍摄参数保持原厂处理；没有对应文字接口的模板保留原样。
- “相册与编辑 → 捕获画面 → 取消截图裁剪最小尺寸限制”独立控制原厂截图和长截图的裁剪下限，默认关闭。开启后可以把裁剪框缩小到原厂限制以下，保留图片边界与有效保存区域；关闭后下一次操作裁剪框恢复原厂限制。
- “相册与编辑 → 图片编辑 → 取消相册编辑裁剪最小尺寸限制”独立控制原厂相册编辑的裁剪下限，默认关闭，不随截图裁剪开关联动。保留有效图片尺寸和边界；关闭后下一次操作裁剪框恢复原厂限制。
- 截图裁剪使用 `com.android.ztescreenshot` 作用域；原厂相册将普通图片编辑交给 `cn.nubia.photoeditor`，相册编辑裁剪使用此图片编辑器作用域。
- 首次安装或更新后，需同步对应原厂应用作用域并重启应用以加载新逻辑。功能在手机端原厂裁剪流程内生效，不需要电脑端程序。

## 声音与音量

“声音与音量”提供“音量面板与按键”“音量增强”和“各类音量档数”。“音量面板与按键”直接显示“音量显示百分比”开关，无需展开额外分组。开启“超过 100% 的音量”后展开步长和各通道上限。

| 设置 | 范围与行为 |
|---|---|
| 基础档数 | 闹钟、媒体、通知、铃声、通话分别设 1–200 档；修改后重启手机 |
| 额外增益 | 扬声器、有线／USB 耳机、蓝牙分别配置媒体、铃声、闹钟上限，100%–300% |
| 增强步长 | 达到原厂上限后，每按一次加键增加 1–20 个百分点 |
| 不追加增强 | 上限 100%、关闭增益，或通知／通话类型 |
| 其他 | 取消音量过高提示；锁屏调音量和长按音量键振动在音量面板与按键 |

例：基础 15 档，上限 150%，增强步长 10%，额外 5 档，面板总计 20 档。百分比是软件增益，不是实测响度同比提升；实际可用效果取决于音频通道。

## 应用安装与网络规则

- “应用管理 → APK 安装规则”三级页直接显示签名不一致安装与较旧 APK 签名方案两项开关，原签名安装入口跳转到本页。
- 同包名不同签名覆盖安装：原校验先执行，再针对签名不一致更新失败处理。覆盖后的应用能访问原数据，仅用于可信 APK。
- 放宽较旧 APK 签名方案要求，与不同签名覆盖分别控制。
- 飞行模式保留蓝牙或 Wi-Fi／热点；两位 Wi-Fi 国家码；固定 Wi-Fi MAC、热点 BSSID。地址做有效性校验，空白不修改。

## 通知与控制中心

星云岛提供场景支持总开关，可分别选择录音、手电筒、通话、音乐播放、倒计时、人脸识别、会议、AI 助手、AI 记忆、充电、低电量、蓝牙、耳机、互传、NFC 文件传输、日程会议、景区导览、附近充电宝、骑行与还车、航班行程、出行前省电建议及异常天气出行建议。新增卡片沿用原厂状态和操作，需启用相应服务及作用域。各场景仍须具备原厂接口，未知结构保留原生行为；关闭总开关恢复原厂场景选择。录音控制按当前用户识别服务能力，接口暂不可用时可重新识别并恢复状态。

原厂魔力岛与旧版星云岛分别识别开启状态和设置入口，并与 Duo 的选择状态联动。魔力岛接入充电、音乐、时钟倒计时、红魔互传、AI 帮写，以及原厂魔姬建议的日程会议、景区、充电宝、骑行、航班、省电、天气、打车、外卖和两类火车票卡片。子项关闭会调用原厂方法撤卡并收起对应面板，重新开启等待新的真实服务事件；原厂授权、时效、开关和操作保持生效。原厂全屏分支不支持 Duo 自绘岛，不提供无效的开启状态。

魔力岛还接入录音、通话、会议转写、通话 AI 辅助、AI 记忆和 NFC 文件传输的真实来源、原厂卡片与操作。AI 记忆在真实收藏任务的处理及结果阶段调用原厂卡片工厂，保留原厂取消、详情和到期规则；需启用 AI 知识后台服务（`com.zte.ai.knowledge`）作用域。NFC 文件传输沿用原厂卡片 ID，并关联原厂互传开关。手电筒、人脸、低电量、蓝牙、耳机在当前原厂魔力岛实现中被跳过，缺少可用的原厂卡片路径，保持不可用；这些场景的旧版星云岛实现继续保留。

- “亮度条与通用磁贴 → 极暗磁贴”控制真实磁贴的加入与移除；点击磁贴切换极暗，长按打开原厂详情面板调节 0～100 强度。按本机系统的极暗接口决定可用性，不限定 NX809J 型号。应用会核验当前前台用户的实际开关、强度和颜色变换；不支持或缺少执行反馈时说明原因，已保存的开启请求仍可关闭。需要 Root 与模块系统作用域，更新后重启手机；工作资料不能控制另一用户的屏幕。
- “系统设置 → 显示与休眠 → 完整亮度”默认关闭，需要 Root，不再按机型名称限制，功能下方不显示机型说明小字。实际运行核验屏幕驱动接口与最大值；匹配当前驱动配置时，手动范围扩展至 1～8190，原厂范围为 2～7030，两端显示“极低 0.5%”和“116.5%”。比例是驱动数值口径，不等于光学亮度或 nit。自动亮度、息屏、省电及系统温度限制会释放扩展控制；Root 不可用或驱动不匹配时保持原厂滑条并反馈原因。

### 通知中心音乐卡片

- 入口：通知与控制中心 → 通知展示 → 取消通知中心的音乐卡片，默认关闭。
- 开启后隐藏通知列表中的原厂音乐卡片并释放其占位；实际音乐播放、媒体会话及其他通知继续由系统处理。独立控制中心播放器和灵动岛不随此开关隐藏。
- 关闭后按原厂最近一次要求恢复显示；播放会话已移除或原厂已隐藏的卡片不会被强制显示。
- 首次安装或更新后需重启系统界面加载新逻辑，之后开关可直接生效。功能适配红魔原厂通知卡片结构。

### 灵动岛

- 入口：通知与控制中心 → 灵动岛，默认关闭。开启后按真实活动显示胶囊，默认使用黑色背景，空闲时隐藏；轻点打开来源，长按展开顶部面板。
- “通知状态自动避让岛”独立开关默认开启：灵动岛或星云岛出现时，沿用原厂逻辑折叠通知图标并预留状态栏空间；关闭后不再因岛出现而避让，图标可能与岛重叠。切换即时生效，保留原有通知显示设置及普通空间不足时的折叠；缺少必要原厂接口时保留原生行为。
- 媒体面板的上一首、暂停／播放、下一首不再立即强制收起，操作后重新计时 8 秒；媒体活动较早结束时仍按原有效期退出（暂停保留 4 秒）。普通窗口缺少全屏面板根视图时，按实际字段和方法能力执行普通窗口的收起收尾；完整全屏窗口及旧版路径保持原厂处理。隐藏、切换或释放前先完成当前面板动画，重复收起只执行一次。
- 展开、收起和调整位置时，仅为红魔Duo持有的灵动岛窗口关闭额外的系统移动动画，避免窗口宽度改变后从旧左边界滑回；胶囊尺寸、触摸范围和原厂形状动画保留。退出或交还原厂窗口时恢复原移动策略；接口不可用则保持原行为并记录原因。
- 音乐活动读取系统媒体会话的封面和播放状态，仅展示后台来源；进入正在播放的来源应用时收起，切到后台且仍在播放时恢复，应用切换无需等待播放状态回调。视频应用也按此规则处理，同名应用的其他用户／分身不视为同一来源；前台识别暂时不可用时隐藏媒体岛。展开后按播放器支持情况提供上一首、播放／暂停、下一首。播放后暂停保留 4 秒控制机会，停止或会话销毁立即退出；初始暂停会话不显示，缓冲与连接状态最多保留 12 秒，前台隐藏期间仍按原期限到期。
- 通知活动短暂显示符合条件的新通知，展开可查看并打开来源；遵循通知重要性、勿扰、当前用户及隐私限制，保留原通知。停留时间可设 3～15 秒，到期或打开来源后退出。
- 充电提示在接通电源时显示 5 秒，不因电量变化延长。启用时已有充电状态只作初始基线。
- 新通知和短暂充电提示结束后恢复仍在进行的音乐。三类活动可独立开关。
- 胶囊宽度 96～240dp、高度 20～48dp、水平偏移 −120～120dp、上下偏移 −24～24dp；上下偏移以居中位置为基准，正数向下、负数向上，实际尺寸和位置受状态栏及屏幕边界约束。可结合组件排列避开相邻图标。
- “背景样式”提供经典黑色、透明和液态玻璃，升级保留原有黑色或透明配置。透明样式仅移除紧凑胶囊背景；液态玻璃同时用于胶囊和展开详情，展开、收起时保留同一材质，文字和播放按钮随背景明暗调整。玻璃采用透色材质与边缘高光，系统支持安全背景采样时显示真实背景折射，否则使用半透明玻璃。未知原厂背景结构保持原样并记录缺失能力。外观参数保存后实时应用。
- “灵动岛显示样式”在灵动岛功能页展开后，点击公共玻璃按钮选择“圆角方形”或“圆形”，默认圆角方形；同步改变紧凑态与展开详情的应用图标、音乐封面，收起参数或关闭灵动岛后保留选择。
- 保留原厂下拉、多指及取消手势。锁屏、息屏、用户切换及状态栏不可见时收起；关闭功能保留参数。首次更新需重启系统界面。

## 操作与手势

侧滑返回内置“初音未来”人物与蓝紫波浪配套预设，可一键应用双侧或分别应用；右侧背景自动镜像。支持仅恢复原厂波浪，人物与背景共同备份，预览升级为组合示意。

- 入口：操作与手势 → 侧滑返回 → 自定义侧滑返回图标。Hook 作用域为 **系统界面 `com.android.systemui`**。
- 左边缘向右滑、右边缘向左滑可分别选择不同图片；支持大小、不透明度、水平镜像、内移及上下偏移。
- 支持静态 PNG、WebP、JPEG、GIF 和动态 WebP，可调 10%～1000% 缩放、透明度、镜像和位置，默认完整显示并透明留边，也可裁剪；保留图片原色。两侧配置可以互相复制，或单侧恢复原厂。
- 总开关关闭保留参数；“恢复本侧原厂”清除本侧配置。图片及两侧参数随模块配置一起备份。
- 首次安装或更新后重启系统界面以加载 Hook；正常修改在图片加载完成后的下一次手势生效。自定义背景沿用原厂手势几何与动画，返回判定和悬停动作图标保持原厂。
- 长侧滑进入快捷方式阶段时，已选初音未来等自定义背景继续显示，快捷方式提示图标和触发行为保留原厂；退回普通侧滑时恢复所选返回图标。
- 当前适配红魔 `SeaWaveView` 绘制路径；图片缺失或其他路径回退原厂。

## 状态栏自定义

统一入口：**通知与控制中心 → 状态栏自定义**。分为状态栏、系统图标、通知图标、素材与字体四组，共用顶部预览及未应用的素材、字体草稿。原八页编辑器保留为“旧状态栏自定义”，描述为“目前保留，但后续会删除。”

- 未修改任何项目时，仅开启总开关保持原厂外观，不写入默认排列，不调整图标大小、位置或间距，也不自动替换锁屏运营商文字。单项修改只应用明确修改的字段；选择并应用预设后才接管完整排列。已有自定义完整方案继续兼容，关闭总开关保留用户配置。
- 组件按左、中、右侧及上排、下排、跨两排设置位置。独立图标详情直接显示 1–999 的数字顺序，数字越小越靠前；组合内元素链接到所属组件。系统图标中依次为通用设置、三合一图标、独立图标配置，位于同一张卡片。
- 独立图标配置保留搜索，可筛选当前已加载、已修改、未显示和全部图标，下拉框右侧刷新图标读取本机最新快照。“未显示”指已经检测到但当前未显示；从未检测到的图标可在“全部图标”中预先配置。
- Wi-Fi、热点和各 SIM 的专属设置归入相应图标；移动网络公共选项在“通用设置 → 移动网络与信号”。网速高级设置在网速详情；硬件指标的“自定义前缀与宽度”开关及参数在各指标详情。通用设置末尾依次为“温度与电量隐藏单位”“隐藏指定图标”“仅充电时显示电流和功率”，隐藏单位与仅充电显示无需开启前缀与宽度自定义。
- 通用设置直接提供“系统图标大小”，开启后显示大小滑条，关闭后沿用原厂大小并记住上次自定义值，再开启时恢复；应用预设或重置会清除此记忆。移除“系统图标默认设置”和“硬件指标共用设置”两层入口。“位置与大小”统一改为“位置”，“显示顺序”与相邻参数标题对齐。
- 三合一图标关闭时隐藏其配置；开启后在同一入口直接提供圆形组件大小、显示顺序、位置及内部图形设置。移除“三合一图形图标”和“高级设置：三合一图标”重复分组。原生电池的专属设置在“独立图标配置 → 电池”。
- 布局统一使用组件排列，已删除旧版表格入口、全屏画布、触摸编辑及其输出逻辑。旧入口跳转组件排列，旧备份中的表格模式不会重新启用。
- 新界面的预设下拉框只提供“简洁单排”“常规双排”，不显示方案说明。先预览再应用，取消恢复原配置，均保留素材与字体。简洁单排恢复原生时钟与单排图标，关闭三合一、自定义网速和额外硬件指标；原厂网速继续遵循系统设置。常规双排采用 2026-10-28 从当前手机记录的样式：原厂高度及四边边距、−1dp 双排间距，左侧双行时钟（`HH:mmIIE` / `MM.ddN月e`），通知组件位于左上区域并开启内部双排，右下排功耗、右侧上行／下行双排网速且不带方向前缀，最右端为跨两排三合一。
- 常规双排的三合一大小为 23dp，圆环粗细 6%、未点亮部分不透明度 28%，开启反向圆环和自定义颜色；上方 Wi-Fi 缩放 189%、纵向偏移 −5%，中间电量缩放 123%，下方双卡信号缩放 100%。完整参数固化于 `StatusBarRegularDualPreset`，预览与应用共用同一份参数。
- “重置状态栏配置”经确认清除四组全部配置并恢复原厂样式；新界面移除旧方案恢复工具及“恢复本组属性”。旧编辑器保留原有历史预设及工具。
- 高度 -32～96 dp：0 遵循原厂，负数在原厂基础上减小（最低 1 dp），正数不低于原厂高度；同时调整状态栏窗口和系统提供给应用的顶部空间，覆盖四个旋转方向。应用自身固定的顶部留白或开孔避让仍由应用决定。四边边距以本机原厂内容边界为 0，范围 −64～64dp，正值增加该侧边距，负值减小；两排间距为 −8～64dp。开孔、高度或间距造成空间不足时保留参数并说明原因，实际排列回退原厂。
- “仅调整位置和大小”保留原生时钟、字体和其他图标样式，双排信号可独立启用；暂停自定义时钟、通知与系统图标分两排、硬件信息和自定义网速。
- 双排间距允许负值并按设定值排列，不再自动避开由负间距引发的上下排交叠；同排碰撞、开孔及屏幕边界保护保留。除主动设置的上下排交叠外，组件排列无法容纳、出现碰撞或无法识别原厂结构时停止整次接管，恢复原生排列并清理自定义层；不会混用部分新坐标。
- 普通参数自动保存；素材、字体和素材页显示设置使用独立草稿，点击「应用」后保存，离开前保护未应用修改。

### 图标素材、字体与显示位置

- 按桌面与应用、锁屏、通知中心、控制中心设置图标素材、字体和额外隐藏；未覆盖的位置沿用共享方案。旧版未分位置的素材／字体自动作为共享配置，包导入保留未涉及的配置。
- 通知中心、控制中心只配置顶部图标区域的外观、字体与隐藏，不重排整个面板头部，也不修改快捷磁贴或通知正文。合并面板共享的顶部区域归于通知中心。
- 额外隐藏关闭后恢复继承，不强制显示原厂当前未显示的图标；已有全局隐藏继续参与最终结果。
- 手机信号直接选择强度子组件，电池分为外壳、电量等部分。复合整图替换不能同时表达各项动态信息时保留原厂，使用状态子组件或背景／前景装饰；断网等状态没有对应素材时保留原厂提示。
- 当前上网卡角色跟随实际活动数据订阅，与固定 SIM 槽位区分。动态绘制保留原生可见性和透明度，不把未知状态当满格，也不把原厂淡化的空闲箭头强行点亮。
- 素材页展示真实状态来源、命中状态、应用／回退原因与组合覆盖关系。各位置观察时间独立，上次快照有明确标识；未检测到不代表隐藏。图样预览是示例。
- 支持整套素材导入、按状态单项覆盖、背景与前景图层、字体角色与位置覆盖、导出分享；字体与图片导入不会立即覆盖运行配置。详细格式、容量与操作见[状态栏素材与字体](statusbar-assets.md)。

### 时钟、通知与系统图标

- 时钟单排／双排、独立行格式、秒、星期、12／24 小时制、时段、字号、字重、字距、宽度和对齐。
- 农历、干支、生肖、节气、时辰扩展格式。离线数据已编入源码，覆盖香港天文台 1901–2100 年历表；`y` 为公历年、`Y` 为农历干支年，固定文字用单引号。
- 毫秒刷新配合有效的 `S` 格式字段，受实际屏幕刷新能力限制；不包含有效毫秒字段时不进入逐帧刷新，息屏暂停高频刷新。
- 通知数量、双排、原生通知图标与数量解限；解限后忽略原数量值但保留配置，仍受屏幕空间和溢出提示约束。隐藏显示不删除通知。
- 蓝牙图标可选原厂、小米胶囊电量和圆环电量百分比，选择界面展示各样式示例，使用原厂当前选中设备的上报电量；未知电量仅显示蓝牙符号。“仅调整位置和大小”暂停样式覆盖。
- VPN 图标可选原厂或圆环样式，与蓝牙圆环共用单圆环矢量绘制，粗细比例一致，随原生状态栏颜色切换；仅替换系统正在显示的 VPN 图标，不改变 VPN 连接状态、隐藏规则与溢出提示。导入的 VPN 素材优先；使用圆环前需清除对应的素材绑定并应用，素材文件保留。“仅调整位置和大小”暂停样式覆盖。
- 切换 VPN 或蓝牙样式时直接更新图标及其占用空间，保留其余状态栏内容和三合一连接状态；选择弹窗与当前页面保持相同的系统栏明暗外观。
- 图标顺序、整体与内部间距、Wi-Fi 与移动网络附属元素间距及隐私提示间距分别设置，按真实图形边界计算。
- 通知区域汇总可用符号、最多 12 字符的短文字或图片替代可显示通知的图标，无通知时消失，图片不可用时恢复原生图标；保留全部原通知。
- 系统图标双排；双卡信号固定物理SIM1上排、SIM2下排，切换数据卡不交换两排，流量箭头及对应素材跟随实际活动数据订阅。双排颜色读取原厂对所在区域实际生效的前景色，收到变化后立即重绘；即使排列稳定，也按最终图形边界处理待更新颜色。颜色未知时保留原厂图标，不以时钟或应用深浅模式替代。
- 隐藏 Wi-Fi 箭头／标准数字、移动数据箭头／类型、大小 HD、各 SIM 信号、隐私绿点。
- Wi-Fi、热点、移动网络可按主屏、锁屏、通知栏头部、合并／独立控制中心隐藏；支持其他图标槽位名单和忽略原厂隐藏限制。
- 双击状态栏锁屏、隐藏状态栏内容、恢复原生字体、挖孔黑圈常显。

### 温度、功率和网速

- CPU、GPU、电池温度、电流、功率独立位置、大小、顺序、前缀、宽度及 0–3 位小数；支持隐藏单位、仅充电显示电流和功率。
- 读取设备实际可用传感器，不把温控阈值当成测量结果。
- 自定义网速上下行组合、单双排、上传／下载标志，标志可以留空；低速隐藏阈值、有效位数、自动／固定单位、`/s` 与固定宽度。
- 原生网速字号独立配置；先在系统中开启原生网速，0 表示跟随系统。

### 三合一与原生电池

- 外圈表示电量；内部上方、中部、下方分别选择电量数字、Wi-Fi、双卡、流量卡、另一张卡或不显示。流量卡与另一张卡仍跟随实际活动数据订阅，圆弧角色保持原有行为，不因双排信号固定槽位顺序改变。
- 每区域独立移动 -100%～100% 图标直径、缩放 50%～300%，隐藏内容时仍保留参数。
- 普通充电闪电、旁路充电插头分别移动和缩放，共用自定义颜色；默认跟随电量数字，没有电量数字时不显示附属标志。
- 未充电／普通充电／旁路充电预览；圆环粗细、未点亮不透明度、低电量与充电颜色；电量字体颜色另设。
- 原生电池可选数字位置、仅图形／数字或隐藏，设置百分号、固定宽度、不透明度和颜色，集中于折叠卡片。
- “电池与三合一 → 原生电池图标”展开内的“电池预设样式”提供原生样式和 ios 样式。ios 素材跟随电量、充电、省电、性能状态及状态栏前景明暗自动选帧，内置数字与外置数字沿用所选电池显示方式。
- “网络与信号 → 双排信号图标”展开内的“信号样式”提供“荣耀双排”和“iOS双排”，默认荣耀；iOS 单卡采用原始单排素材，双卡采用上柱下点的双排素材，两卡强度分别取图，颜色随原厂所在区域的明暗变化。实际可见单卡自动采用单排，双卡固定物理卡1在上、卡2在下；仅卡2可见时也只显示一排，流量卡切换只移动活动箭头。关闭双排或选择原厂平铺保留样式参数。

## 系统设置与 USB 连接

## 桌面与最近任务

- “隐私屏”提供“启用隐私屏”开关和应用多选。在最近任务中模糊所选应用画面，并居中显示清晰的红魔 Duo 图标，保留卡片名称、打开与清理操作。关闭后保留应用选择；同包名分身共用选择。首次安装后需重启系统桌面加载功能，随后修改即时生效。当前已在 NX809J、桌面 260029 验证；其他桌面按卡片绘制和任务身份接口检测，缺失接口保持原厂行为并记录原因。此功能不禁止应用内或系统截图。

- “桌面布局与页面”新增“强制新装APP图标显示在桌面末页”。开启并重启系统桌面后，新安装应用的图标放到末页，末页没有空位时新增一页；不移动已有图标，不改变更新应用的位置。适配 10、11 系列桌面。

- 最近任务内存：开关、简洁／详细样式、可用／已用／总量组合、字号、深浅颜色、横竖屏位置和区域高度。使用实际物理内存，不改任务卡片布局。
- 横屏位置入口：在“桌面与最近任务 → 自定义最近任务内存显示”右侧展开配置，向下滚动到“横屏内存距顶部”和“横屏内存距左侧”。两项均为 0～2000 dp，以横屏方向的顶部、左侧为基准；超出可见区域时限制在边缘，与竖屏位置分别保存。
- 修改版桌面检查位于日志及运行诊断，仅读取兼容信息，不安装桌面。独立桌面源码和 APK 不在当前项目。

## 游戏空间

“主页 → 游戏空间”二级页面提供“肩键与极速连点”“一键连招”“性能与超分”“游戏插件”和“录制、高光与红魔时刻”五个分组入口，每组为一个三级页面。组内直接显示功能开关，参数在对应功能内展开；旧功能入口跳转到所属分组，沿用已保存的配置。极速连点与全应用肩键使用一致的功能行，不显示行内描述或兼容性测试按钮；未通过测试时点击开启，会提示“请先进入兼容性测试”并打开独立测试页，开关保持关闭。

“游戏插件 → 自定义性能监测”可选择原厂性能监控浮窗的时间、FPS、网速、电量、游戏时长，以及电池温度、CPU 温度、GPU 温度与功耗，至少保留一项。原有项目沿用原厂数据，新增温度读取实际传感器；功耗显示电池净功率，充电时为充电功率，不能读取时显示不可用。新增项目使用与原厂项目一致的单行显示。背景透明度可设 0–100%：0% 不透明，100% 完全透明，文字和图标保持原厂显示。先在游戏空间开启原厂“性能监控”插件；模块在手机端调整显示项目、宽度、点击区域与背景。关闭自定义后恢复原厂显示，保留已选项目与透明度。按 GameAssist 16／17 的两套完整接口适配，保持 17 路径优先，整套校验后才注册，不能混用两版成员；具体可用性取决于本机原厂结构。

“监测项目间距（dp）”调节所选项目之间的左右间隔，0 保留原厂间距，负值压缩间隔且可能使文字重叠。范围根据监测布局的项目宽度、字号、屏幕空间及所选项目计算，单项目没有可调间隔。先打开一次原厂性能监测取得当前字号的实际布局；缺少布局信息时暂不可调。保存值超出当前布局范围时显示保存值和当前实际值，不覆盖原设置。

性能监测和肩键方案快捷切换分别提供“长按固定悬浮窗位置”。启用后长按固定，再次长按解除；固定期间仍可点击；再次进入时按保存的位置恢复并校正系统边界，关闭选项恢复拖动。

肩键方案快捷切换与已通过兼容性校验的极速连点同时开启时，按连点改写后的实际频率确认方案执行结果，仍核验坐标、模式及底层调用异常，保留已保存的原厂方案。

- 全应用肩键：向加入游戏空间的应用开放原厂肩键。
- 极速连点 **1–50 次／秒**，默认 20 次／秒，按住触发、松开停止。首次进入兼容性测试页后，手动开始测试；测试核验 Root、目标组件、系统层与原生库，再分别采集左右实体键，验证实际节拍、松开停止和稳定性。通过只解锁功能，返回肩键页后手动开启。普通红魔Duo升级保留已通过的认证；系统版本、游戏组件、系统输入库或肩键兼容协议变化时才要求重新测试。同环境下的旧版完整通过凭据兼容沿用，不恢复已被关闭的功能开关，也不绕过熔断。
- 肩键方案快捷切换：原厂页勾选参与方案，一个直接应用、两个互切、多个下拉选择。
- 连招 **1–10 倍**播放，保留原始录制，下次播放使用新倍率；循环次数可输入六位数，间隔最长一小时。
- 连招倍率生成的派生文件保存于红魔Duo私有缓存，播放时通过受控的只读接口使用；旧模块派生文件安全清理，原厂原始录制保留。
- 向其他性能模式开放原厂超分，阻止超分与破坏神自动互斥，保留主动关闭。
- 隐藏破坏神提示、切换模式保留面板、按游戏记住活跃模式。
- 原厂插件资格、高光、随心录制、红魔时刻的已适配限制；原始、4:3、16:9、21:9、32:9 比例。
- “游戏插件 → 开放游戏插件资格”同时接入原厂超境画质能力和处理输入尺寸适配，原厂界面保留真实能力查询与用户开关，修复扩展应用的画质、帧率选项缺失。安装后重启手机，启用后重新进入游戏，再在原厂超境界面选择画质、帧率；新处理会话在手机端自动适配输入，不修改全局屏幕分辨率或触摸坐标。关闭恢复原厂能力与输入限制，停用原厂不支持应用的增强并保留档位参数。已创建的会话在重新进入游戏后恢复原厂尺寸；更高档位、格式、帧率及其他设备仍受原厂引擎限制。
- AI 参数：模板扫描 80–2000 ms、点击队列 10–500 ms、策略冷却 50–2000 ms、YOLO 扫描 150–1500 ms。实际触发仍受识图、模型和点击耗时影响，首次启用按提示重启游戏作用域。

## 散热风扇

风扇控制页将“固定风扇转速”“息屏风扇不停止运转”与“散热风扇磁贴增强”放在首张卡片，各开关独立保存。固定档位沿用公共选择布局，收起或关闭固定转速只隐藏其档位，其余功能行仍显示。“本机转速测量”独立放在下方第二张卡片。

- **固定风扇转速**：只保留一至五档，直接使用所选硬件档位，不依赖本机测量；已删除“转速”方式及“目标转速 RPM”调节。风扇开启时不受原厂智能／极速模式选择影响，按所选档位固定。跟随原厂开关；在模块设置内，风扇关闭时也可保存档位，不自行启动风扇。
- **息屏风扇不停止运转**：默认关闭，保留 NX809J 原路径，另支持本镜像已审查的 NBFan 策略，按实际 APK 与运行时接口核验。让已经运行的风扇会话在息屏后延续原厂模式，不自行启动已关闭的风扇、不强制指定转速。手动关闭、通话、关机和原厂保护继续生效，快充仍走原厂已有策略；关闭功能恢复原厂息屏处理。首次安装或更新后需重启风扇作用域。红魔12 Pro+ 的物理运行效果待真机验收。
- **本机转速测量**：先打开原厂风扇，约一分钟内逐档检测一至五档，保存稳定转速及最高反馈，仅用于查看本机各档实测表现，不参与固定档位控制。完成后恢复原档位；取消、关闭风扇或切换原厂模式会停止检测。系统或固件变化后可重新测量。
- **散热风扇磁贴增强**：独立开关，默认关闭。通过本机档位能力核验后，开启增强并打开原厂风扇，长按控制中心的散热风扇磁贴，原厂详情面板中显示“固定转速”，支持一至五档拖动及实际档位／转速反馈。风扇关闭时保留原厂提示，不显示档位设置；先打开风扇后再调节。开启增强开关本身不会启动风扇或启用固定转速；关闭增强后恢复原厂长按面板，固定转速仍由自身开关控制。当前不支持第六档。
- 固定档位与逐档测量保留 NX809J 路径；新路径必须匹配已审查驱动字节、运行中模块身份、内核及实际节点和恢复接口。设置、控制中心和执行端共用能力证据；没有证据不凭机型名称开放。NX769J 保留原厂全速接口，不借此开放未验证的逐档写入。
- 未适配机型的风扇增强开关显示关闭并禁用，页面直接说明原因；已保存的参数继续保留，打开页面、返回和旋转不会清除配置。
- 各档实际 RPM 会随设备状态波动，不是无级调速，也不保证达到标称 RPM 或突破硬件极限，可用性以设备接口为准。

## 电池

入口：系统设置 → 电池，原电池健康度入口自动跳转至此。

“省电模式保持当前帧率”使普通省电模式不再额外施加刷新率上限，继续遵循原有刷新率设置、应用策略、温控及超级省电限制；不写入固定刷新率。关闭后由原厂处理线程重算原策略。安装新版后需重启手机加载系统服务适配。

电池健康度分组中点击“开始检测”读取本机可用电池接口，显示估算健康度、满充容量、设计容量、循环次数与数据来源；可手动重新检测。健康度根据满充容量与设计容量估算，会随电池计量校准变化；缺少必要数据时显示“无法计算”或“不可读取”，不补造数值。

## 小米运动健康

- 先打开健康应用等待账户接入，再绑定当前本机账户；换账户后重新绑定。
- 真实步数 **1–10 倍**计入新记录，计划增加的步数不再乘倍数。
- 随机增步设置时间范围、星期、次数和每次步数；每天 1–100 次、不同分钟执行，每日计划总量不超过 1,000,000 步。
- 支持跨午夜，星期归开始当天；当日已经生成的随机时间表保持稳定，修改用于下一执行日。
- 当日上限 1–1,000,000 步，仅停止额外新增；真实步行继续、不减少已有记录，提高／关闭上限不补发先前受限步数。
- 后台需允许健康应用自启动和后台运行；强行停止后重新打开。同步走健康应用，关闭计划不回滚已存步数。
- 模块防重复计步和计划执行记录保存在红魔Duo私有数据库。旧模块记录完成校验和迁移后才清理；冲突或迁移失败时保留数据并提示，不重新生成可能重复的增步。原厂健康记录、登录状态及云端数据不作为模块缓存清理。

## 四大皆空

在“关于”的“系统版本”连续点七次，相邻点击间隔不超过两秒。返回主页且搜索为空时出现入口；离开应用前台后重新锁定，已隐藏应用不会因此自动显示。

- 三级页直接管理应用名单、锁屏自动隐藏和快捷磁贴。应用名单卡头显示配置数与隐藏数，名单默认收起；空间选择、刷新和本范围隐藏／显示始终可用。展开后可搜索名称／包名、切换已配置／已隐藏／全部应用并按名称／安装时间排序；“选择应用”直接展开全部候选，勾选后自动保存到对应空间的名单。收起只隐藏列表，保存、刷新、空间切换及单项操作不会重新展开。
- “隐藏本范围／显示本范围”操作当前选定空间的全部已保存名单，确认弹窗注明空间与应用数量；搜索和列表筛选不会缩小批量操作范围，执行后显示核验结果。
- 每行显示应用名称、包名、空间及当前状态。全部应用视图只勾选名单；已配置／已隐藏视图提供单一“隐藏”或“显示”按钮，操作前确认应用名称与空间。点击应用名称区域可管理名单；取消勾选或移出名单只改配置，不自动显示。
- 应用隐藏关闭后仍保留名单和现有隐藏状态；列表、单项显示及本范围显示始终可用，隐藏操作需先开启应用隐藏。
- 应用隐藏启用及隐藏／显示操作检查 Root 授权；Root 暂不可用时在操作反馈与功能帮助中说明原因，不在开关下常驻运行环境小字。锁屏自动隐藏需 Root、系统框架作用域、应用隐藏开关及已配置名单；同时核验当前版本、本次启动的监听与真实配置桥接已就绪。监听在功能关闭时也会注册并上报，首次开启无需先运行自动隐藏；尚未加载当前版本时明确提示重启手机。快捷磁贴和自动隐藏在主开关关闭时保留设置并显示暂停状态；磁贴开启后可独立收起，其他设置变化不会重新展开。
- 自动隐藏实际由系统亮到灭事件触发，每次最多执行一次，可选当前或所有已配置空间；解锁不自动显示。
- 磁贴自定义图片、名称、说明；混合状态优先全部显示，关闭动作后留在面板但不操作应用。
- 空间身份不明、名单异常、环境不满足时保留记录并提示，不把未知用户当成用户 0。
- 名单、事务及恢复记录保存于红魔Duo私有目录。升级先保存并核验旧记录，再删除确认未变化的旧源；迁移完成凭据会持久保存，之后普通读取不再每次访问旧 Root 目录。实际隐藏与显示操作仍按需使用 Root。卸载会删除应用私有记录，应先显示需恢复的应用。
- 历史恢复和事务类仍在源码中，但当前 Manifest 未注册 `HideRecoveryActivity`，页面也无旧“应用显示与历史”入口，不能当作当前可访问功能。

## 模块维护与关于

- 设置页隐藏／恢复模块桌面入口，隐藏后可从框架模块设置进入。

- 关于包含本地设备信息、贡献名单、支持图片和使用说明。网络权限用于获取 HTTPS 贡献名单网页；页面先显示构建时保存的离线快照，再请求最新网页，失败时保留快照。健康同步仍由健康应用负责。
- 电池老化电压策略退出当前产品入口；`BatteryLifeControl` 仅做旧覆盖清理，旧 `battery` 页面直接退出。
- 模块自有配置、缓存及恢复记录使用应用私有存储；已删除旧外部启动快照实现。按用户要求保留框架官方开机配置副本，通过官方 remote preferences 接口发布，由框架自身数据库持久代管。配置、素材及日志导出由用户选择文档位置，主动导入的系统铃声继续通过系统媒体库管理；这些明确操作不会变成自动写入公共目录的模块缓存。详细迁移边界见[模块私有存储](模块私有存储.md)。
- 独立修改版桌面不在本项目构建范围。网页原型已同步当前分类及部分编辑界面，底层仍含历史样例数据，按钮和读数不代表手机执行结果。

## 兼容性

最低 Android 15（API 35），目标 Android 16（API 36），原生库为 arm64-v8a，需要支持 libxposed API 102 的框架。主要适配基准为 NX809J／RedMagicOS 11.5.7MR1／Android 16；风扇固定档位、测量与息屏延续限定已适配的 NX809J；完整亮度按实际 Root 和屏幕驱动接口判断，不再按机型名称限制。游戏性能监测按 GameAssist 16／17 的完整接口适配。

最低系统、ABI、框架接口是安装与加载条件。具体功能还依赖原厂类、方法、资源和硬件，设备适配基准在 `android/app/src/main/assets/redmagic-baseline.json`。功能不可用时按页面提示和日志检查本机接口。

开发环境与构建见[跨设备开发说明](跨设备开发说明.md)，文件职责见[项目结构说明](项目结构与文件说明.md)。
