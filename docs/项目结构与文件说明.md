# 项目结构与文件说明

版本：`2.0.0-alpha1-test20354`。核对日期：2026-09-23。

本索引以用户手动精简后的实际目录为准，逐一列出项目文件，包括被忽略但目前仍存在的文件；`.git` 内部对象不逐文件展开，统一解释。用途依据源码、入口注册、构建脚本、配置目录和脚本内容整理。历史测试脚本、候选实现和兼容数据仍是有价值的源码，但不等于当前界面提供了对应功能，也不代表其现在可以无输入运行。

## 源码如何协作

1. `SettingsActivity` 展示入口，`HookAppCatalog` 决定应用分类，`EnhancementSettingsActivity` 与各 `*EditorController` 呈现功能。
2. `ConfigSchema` 校验设置；`AppConfig` 保存应用私有配置，经 `FrameworkConfigSync`、`LSConfigProvider` 等路径向授权 Hook 提供状态。诊断和运行证据与功能配置分开。
3. `java_init.list` 指向 `hook.AugmentModule`，后者继承 `RootEarlyModule`，再按目标进程安装对应 Hook。具体能力须由目标原厂接口匹配与运行条件决定。
4. 隐藏应用由目标名单、用户身份核验、Root 队列与事务组件共同处理；历史记录的存在不等于允许重新执行动作。`Root*` 中保留部分候选／离线模型，不能把这些类全算成已投入使用的功能。
5. 连点通过应用侧兼容测试、游戏层／系统层 Hook 和 C++ 原生输入链路配合。状态栏与预览复用布局／绘图规则，真实数据来自 SystemUI 和设备读取。
6. 网页 `app/page.tsx` 进入 `current-prototype.tsx`，读取 test20288 的 JSON 快照与浏览器状态；不会远程操作手机。

## 手动精简后的状态与缺口

- 当前没有 `红魔助手/`、`LS_RedMagicLauncher/`、`redmagic-launcher/`、私有签名备份、`out/`、`outputs/` 或 `audit-output/`。忽略规则仍保留对应名称，防止以后生成的产物进入 Git。
- 旧 `docs/` 功能历史已清空。本轮重建四个当前文档，README 不再链接不存在的历史说明；源码同步与正式安装包发布分开说明。
- 日历原始 200 份表格不在目录中；`ChineseCalendarData.java` 已保留，常规构建无需重新下载。只有再生成数据时需要先运行抓取工具准备输入。
- 网页导入、裁图和对照所需的 `out/ui-faithful/`、`outputs/ui-refresh-20288/screens/`、`outputs/prototype-current/` 不在项目；现有 JSON、字体、图片仍可支持原型运行。缺输入时不要执行会改写基准的导入脚本。
- 许多真机脚本保存了当时的测试轮次、应用样本或证据路径，不能保证任意环境直接运行；运行前检查参数、ADB 环境、所需原厂 APK 和对应资料。本轮未执行设备脚本。
- 已恢复根目录 `.gitattributes`，固定源码 LF 与 Windows 批处理 CRLF。应用 Shell 资源应保持 UTF-8 无 BOM、LF；`android/app/build.gradle` 有校验。没有构建缓存和 node_modules 是正常状态，独立克隆已验证可重新下载依赖并构建。
- 私钥不在项目；公开证书不能替代私钥。重新构建能否覆盖旧 APK 取决于实际提供的签名。
- `BatteryLifeControl` 是升级清理；`HideRecoveryActivity` 当前未在 Manifest 注册。网页旧页面和组件库保留作设计上下文，不全部视为当前入口。
- 配置目录存在五个外观字段，但当前手机设置主页未展示全部旧外观入口；完整字段表与实际用户功能说明需同时阅读。
- 风扇旧文案断言与状态栏模拟测试缺项已修正；125 组项目检查、Java 回归、Android 编译、网页检查与构建已通过。复现范围和环境见[跨设备开发说明](跨设备开发说明.md)。

## Git 内部目录

`.git/` 保存版本历史，应整体保留，不是 Android 编译产物。`HEAD` 表示当前检出引用，`config` 为本地仓库设置，`index` 为暂存区，`objects/` 保存 Git 对象，`refs/` 和 `packed-refs` 保存分支／标签引用，`logs/` 记录引用变化，`hooks/` 为 Git 事件脚本，`info/` 存放仓库辅助设置。内部文件数量随 Git 操作变化，不纳入下方业务文件统计；不存在的可选内部文件不要求补建。

`description` 是仓库描述；`index.lock` 是 Git 写入锁，不是源码。同步前发现一个遗留空锁文件，核实没有 Git 进程后已移至系统临时目录备份。以后遇到锁文件仍须先排查正在运行的 Git 操作。
