# 红魔Duo UI规范

更新日期：2026-11-13。自 test20426 起执行，适用于所有新增、调整和重构的 Android 原生页面、网页原型、弹窗及多级功能界面。实施前必须阅读本规范；后续界面均按本规范设计和验收。

## 设计基准与优先级

- 主页、模块、关于是现行视觉基准。各功能页沿用同一背景、配色、卡片、字号、图标、开关和交互，不为单个功能另设视觉体系。
- 复用 `UiKit`、`AppearanceController`、`LiquidGlassLayout`、`GlassIcon` 及既有输入、弹窗和折叠组件。借鉴 MIUIX 时只在现有体系内改善交互，不引入与主页不一致的大标题、大卡片或多层装饰。
- 用户最新明确要求优先于本规范；本规范优先于旧原型、旧截图和历史发布记录。test20421 的“首张功能卡片与主页聚合卡片顶边对齐”已被本规范的紧凑导航间距替代。历史记录只用于追溯。
- 功能必须由手机端实现；网页原型与开发工具不能成为用户使用模块的前提。

## 导航与纵向间距

二级及更深页面采用“顶部操作栏 → 路径导航 → 内容”的结构。路径导航显示当前位置并允许返回上级；已有路径标题时，不再重复放置页面大标题。

| 项目 | 规范 |
|---|---|
| 路径导航底边 → 首个分组标题顶边 | **总计 8–12dp，默认 8dp** |
| 无分组标题的页面 | 路径导航底边 → 首个内容控件顶边同样为 **8–12dp，默认 8dp** |
| 首个分组标题额外上边距 | **0dp**；导航框架已经提供 8dp 间距，不得重复添加 |
| 分组标题 → 所属卡片 | 16dp，与现有分组样式一致 |
| 常规页面左右内容边距 | 16dp |
| 普通相邻卡片间距 | 使用现有 8–12dp 节奏，不以空白填满屏幕 |
| 主页既有节奏 | 标题 → 搜索卡片 22dp；搜索卡片 → 应用列表 12dp |

“总间距”包括路径栏下方占位、内容容器上内边距及首个标题上外边距。以路径栏和标题控件的实际布局边界测量，不以字形墨迹边缘或截图物理像素直接替代 dp。状态栏安全区不计入这段距离。

**禁止**根据主页标题高度、搜索栏高度或主页卡片绝对位置计算二级页面顶部留白。不得用透明 View、空标题、固定高度容器补回旧的对齐空白。系统字体放大时允许文字控件自然增高，导航后的间距仍保持 8–12dp；横屏、宽屏也不因画面空旷而增加这段留白。

公共实现：`UiKit.DETAIL_CONTENT_GAP_DP = 8`，由 `detailChrome()` 统一提供；`detailPage()` 复用该框架。分组标题使用 `addDetailSectionTitle()`，首个标题不再添加上边距。嵌入式编辑器只提供内容，间距由宿主统一承担。

## 卡片、文字与控件

- 卡片优先使用 `preferenceCard()` / `card()`，服从用户的圆角或直角卡片设置，保留公共玻璃材质和浅色、深色主题，不为单页硬编码背景、描边和透明度。
- 标题、说明、状态使用 `UiKit.text()` 的公共字级和色彩角色，保留系统字体缩放。路径栏沿用 13.225sp；不得重复应用紧凑字号转换，也不得用缩小字体弥补布局溢出。
- 普通导航行复用 `preferenceRow()` / `groupRow()`；功能行复用 `featureRow()`。开关、帮助入口和末列展开箭头保持同列对齐，不因功能名称长短移动位置。
- 右向箭头仅表示进入下一级页面。当前页操作使用动作按钮，已展示的链接、更新包等内容可直接点击复制，并明确提示复制结果，无需另设“查看链接”按钮。属于某个功能的内容和操作放入该功能的展开区域，不另建带右箭头的独立导航行。功能行的向下／向上箭头只表示展开／收起。
- 延续现有尺寸：常规导航行至少 48dp，功能行至少 44dp；开关轨道 46×28dp，滑块 22×22dp，展开列 25×44dp。输入框和星期选择等主要编辑控件至少 48dp 高，不为压缩留白缩小触控区域。
- 使用既有图标资源与统一线条样式。辅助说明放在对应功能帮助或明确的状态位置，不堆叠重复的说明卡片。
- 更新包条目优先展示起止版本、地区和明确标注的固件分支，省略已识别格式中的随机前缀、重复编码和下载接口路径；复制仍使用完整原始链接。不得将固件分支当作设备型号，或未经确认换算为系统宣传版本；时间注明“提取”，避免误解为发布日期。

## 交互与功能状态

### 统一参数编辑

- 展开区域统一由公共折叠组件提供连续的低对比底色、细边界和内容侧线，标题、摘要及配置保持明确归属。内容起始缩进至少 12dp、末端留白至少 8dp，展开内容后留 8dp 分隔；不得在标题与内容间叠加旧的上外边距。嵌套子组沿用相同标识，不额外叠加玻璃大卡片或阴影。允许多个功能同时展开，开关及展开生命周期不变。
- 数值项默认把参数名、当前值及独立帮助入口放在同一个紧凑信息区，由 `NumericParameterHeader` 统一布局；长标题、大字号及“已保存／当前实际”等长状态自动上下排列，文字不截断、不缩小。普通单行信息区至少 44dp，紧接 20dp 的滑条显示行，二者实际控件边界间距为 0–4dp；相邻滑条参数使用约 4dp 的分隔，其他输入控件保持约 8dp。不得再将普通标题和当前值各占 44dp 后纵向堆叠。验收同时检查文字到轨道及相邻轨道的可见距离，不能只检查两个控件边界间是否为 0dp。

- 滑动条统一由 `UiKit.slider()` 创建，使用同一系统轨道与滑块、主题强调色，当前值单独显示。按用户 2026-10-25 再次收紧视觉留白的要求，自 test20636 起显示行由 48dp 调整为 20dp；若系统滑块的原生尺寸更大，保留其必要高度，不能裁切滑块；公共 `SliderTouchDelegate` 将候选响应区域向上下空白扩展至 48dp，不增加布局占位。标题、数值、帮助及其他已有控件优先响应，扩展区域不能截获它们；受父级边界或相邻控件影响的区域不计作独占触控面积。须真机验证原生拖动、空白区拖动、禁用及横向坐标映射，不得仅凭候选矩形宣称实际独占触控高度。不得另建功能专用滑条外观，也不在步数倍率两侧添加加减按钮。
- 有上下界的通用数值参数使用 `ParameterSlider`，整数按 1 调节，小数按 0.01 调节；保留专用编辑器已经定义的有效步长。范围来自配置校验与实际生效代码，受设备空间影响的参数另核对本机几何约束。已保存值超出当前设备可用范围时同时显示保存值和当前实际值，不静默覆盖。
- 适合连续数值调节的参数，统一使用 `NumericParameterEditor` 提供标题与当前值点击入口、精确输入弹窗、范围及步长提示。页面不常驻数值输入框；通用参数由 `ParameterSlider` 组合使用，专用滑杆复用同一编辑器与 `UiKit.slider()`。标题帮助按钮继续独立响应，数值点击区至少 44dp，弹窗输入框至少 48dp；滑杆采用上面的显示行与空白触控扩展规则。
- 精确输入以十进制校验，不静默截断、取整或夹到范围内；空白、越界及不符合有效步长的输入显示错误并留在弹窗。取消、返回或关闭弹窗不写入；确认时再次检查当前可用范围、控件状态及数据是否变化。失效、关闭或离开页面的控件不能提交旧弹窗内容。
- 滑动与精确输入必须走原功能的校验、预览和保存路径；实时变化、松手提交、延迟自动保存、草稿保存和组合事务不得互相替代。百分比按界面展示值输入并转换回原存储单位。颜色保留色盘和 HEX 专用编辑器，时间、枚举、文本及资源选择保留各自适用控件。
- 文本与 HEX 输入统一使用 `UiKit.styleInput()`，高度至少 48dp，保留原有输入校验与无效输入反馈。颜色配置均提供 `UiKit.colorInput()` 和公共 `ColorEditorDialog`，包含色盘、色相、不透明度、HEX 及预览。
- 下拉框统一使用 `UiKit.choiceSpinner()`：公共玻璃输入表面、14sp 字级、48dp 高度、统一展开箭头与选择弹窗。所有功能页、嵌入编辑器和弹窗遵循同一规则。
- 已有卡片中的短枚举可使用 `UiKit.inlineChoiceSpinner()`，在标题右侧显示当前值和下拉箭头，仍使用相同的选择弹窗及至少 48dp 高度；箭头在控件内单独预留空间，不覆盖文字。卡片内次要操作可使用无填充的 `UiKit.textButton()`；同级横向分组可使用 `UiKit.sectionTab()`，用主题强调色文字和短下划线表示选中状态，保留至少 44dp 触控高度。这些样式按需使用，不批量替换现有主操作按钮。
- 布局行列保留公共按钮风格的常用布局；行、列分别使用公共数值编辑组件，支持滑动与点击标题／当前值精确输入。桌面仍按完整布局提交，控制中心仍按对应字段提交；各自真实范围与开关状态保持不变。
- 方向描述统一使用“上下”，不在同类功能中交替使用“垂直”。
- 竞技键“上推动作”“下拉动作”是各自配置卡片内部的分组标识，必须放在卡片内；距卡片顶部 8dp，标识到下方选择控件 8dp，不作为卡片外标题显示。

- 开关控制真实功能是否生效；展开只控制参数显示。每次首次进入功能界面时，全部配置默认收起，包括已经开启的功能。用户在当前页面主动开启功能后可展开，关闭后收起，关闭状态不能展开；单独收起不关闭已启用功能。旋转或进程重建恢复本次页面的展开状态，普通运行状态刷新不得自动展开。
- 关闭功能保留有效参数和已有用户数据。应用显示恢复、素材管理等确有必要在关闭状态使用的工具，可沿用明确标注的既有例外，不能把配置编辑误表现为功能已经启用。
- 有账号、权限或服务前提的功能，开启前检查条件，不满足时提供明确原因及可执行入口，不能只改变开关外观。
- 小米运动健康必须核验绑定账号后才允许开启功能，已绑定状态显示实际小米账号；倍率、随机计划和上限分别受自己的开关控制。
- 自动保存保留原有行为，失败或无效输入必须反馈。普通功能页不重复添加“设置自动保存”“生效说明”等固定页脚，也不堆放与当前操作无关的“运行与帮助”分组。
- 返回、路径跳转、重建和滚动恢复保持一致；有未提交草稿的编辑器继续提供既有退出保护。加载或状态变化不能让内容跳动或挡住操作。

## Step 工作区按格数布局

- 主区、副栏、顶部控制区、动画和输入映射共用 `WorkspaceLayout`，依据配置的侧格数量计算，不能依据当前已占用格数改变整屏比例。
- 依据用户 2026-11-11 确认的方案三，顶部内容区固定为屏宽的 9/16。工具栏从左右边缘呼出，两翼覆盖范围仅限顶部；音乐与顶部应用保留在下层。呼出、向外收起不得暂存或归还顶部任务，不改变主副区几何和任务身份；收起后继续展示原顶部内容。音乐与顶部应用仍可在顶部横向切换。
- 新布局各工作区间距为 0。副应用保留完整原始宽高比，按实际行高计算副区宽度；主应用须通过原生任务配置重排到剩余区域，再做等比缩放，不拉伸或裁切来消除黑边。只允许像素取整产生的小于 2px 误差。无法核实原生重排接口时保留旧几何并明确记录缺失能力，不宣称新布局已生效。
- 双侧工具栏按用户要求复用已安装游戏空间的原厂黑金边框资源，通过资源名和图片结构检查选择路径，不硬编码资源 ID 或机型。背景透明度为 217/255，顶部黑色标题带与原厂灯带独立叠加；300ms 加速减速动画同时驱动两侧位移和透明度，关闭向两侧外移，中途反向从当前位置连续运行。原厂资源缺失或系统窗口不可用时记录具体原因，保留原有三行工具页，不宣称已启用原厂样式。
- 按用户 2026-11-12 后续要求，左侧固定顶行为最近媒体、最近文件、剪贴板三个入口，第二行起为两列滚动网格，第二行按顺序为退出 Step、主区左移（主区已在左侧时显示右移）；第三行为截图、录屏；第四行为主顶交换、移到顶区（已有顶部任务时改为移到主区）；第五行为顶部壁纸、布局设置。左侧删除快捷应用入口，右侧加号及 App 长按仍可编辑。当前任务具备的其余工具接在这四排之后，不挤占固定位置；缺少截图等真实能力时对应位置保留不可点击空位，不伪造功能。右侧固定顶行为已设顺序的前三个 App，第四个 App 起进入下方两列网格；唯一的“＋”紧随最后一个 App，不足三个 App 时允许加号在顶行，无 App 时仍可添加。顶行利用亮度／音量输入带上方的较宽原厂轮廓，保持与下方相同的图标外框，不将三项挤入原两列的窄宽度。空位不可点击，不以假 App 补位。保留 App 长按编辑，不新增“快捷应用”标题或收藏图标。上下滚动及惯性滚动不能阻断下一次向外收起手势。内容选择与编辑弹层继续使用公共组件。
- 按用户同日补充反馈，侧栏新窗口先绘制收起姿态，再从下一帧开始完整的原厂 300ms 呼出动画；重复同方向请求不重启动画，中途反向仍从当前进度接续，退出时清理待执行的首帧回调。快捷 App 图标在列表更新时加载，不在每次呼出时重新清空加载。
- 按用户 2026-11-12 最新要求，两侧固定首行三个图标不显示文字；从第二行起保持两列，在图标下方显示功能名或真实 App 名称。名称使用 StepMaterial 公共文字组件、按用户同日追加要求采用 8sp 单行小字，保留系统字体缩放、不换行；短名称居中，超出可用宽度时自动循环横向滚动显示，完整名称继续用于无障碍和提示。图标与文字保留 2dp 间隔，行高增加实际字体高度，不缩小图标或文字来塞进原方形行。按用户 2026-11-12 对图标仍小、两侧空余和不匀称的反馈，取消56dp固定窄网格及28dp条目限制：从外侧6dp边距开始，以实际原厂边框轮廓和亮度／音量完整输入带为内侧边界，保留4dp间隔，两侧下方共用等宽列并对称排布，图标区保持方形，名称区位于其下。工具、App及加号共用图标外框，尺寸为下方单元边长减8dp、上限40dp；StepGlyph在侧栏内同步放宽绘制上限，不只放大空白容器，其他界面仍沿用默认22dp绘制上限。普通条目透明，选中项使用随单元尺寸变化的细金色圆角描边，角标保留深色衬底；不恢复普通条目的大块底板。触控区按实际单元尺寸计算，不将不足44dp的单元宣称为44dp触控区，常规设置页不受此例外影响。顶部避开开孔，底部保留6dp边距，滚动区域明确限制在顶部窗口内。不以加大系统字号改变列数或挤占主副工作区。末尾加号作为最后一项，下方网格奇数项末行补不可点击空位。工具复用 StepGlyph，并统一为 1.7/24 的圆端线条；最近媒体使用叠放媒体与播放标识、文件使用文件夹与文档、剪贴板使用夹板清单。布局使用工作区分区图，快捷应用使用应用格与加号，壁纸使用手机内山景，移至顶部／主区使用跨分区箭头，主区左右移同时显示主副分区，横屏使用旋转手机，小窗使用靠边窗口，截图使用裁切角与剪刀，录屏使用屏幕与录制圆点，退出使用门扇与向外箭头，钱包使用带扣钱夹。不同功能不可复用含义不符的书签、通用箭头或相同轮廓。保留完整控件无障碍名称、真实状态角标及 App 长按编辑。
